102：普通通道，扣运力的钱，活动通道，扣回收公司的的钱。都是在回收公司支付时扣，一个是回收公司要多付，一个是正常付

# bd_terminalnode

supplier_id：通过代理商邀请码进来的门店。不一定是他代理区域内的门店。



# hs_earnest_money

支付宝相关的定金，包括电池定金和空车定金



# hs_pedlar_order_detail

运力订单

**total_price**: 订单金额

**order_price**: 定金付后，这个值是定金的金额；尾款结后这个字段值是尾款金额，尾款一般分成铅蛋钱包+线下支付的方式，所以 `尾款 + 定金金额 一般小于 订单金额`

**channel**：001活动投售

**state**：

**时间**

order_date: 运力接单时间

# u_recovery_area

回收公司覆盖范围

# p_recovery_quoted_terminal

回收公司向门店报价的表



# hs_miniprogram_user

小程序用户表，回收公司没登陆小程序的话，会存在bd_recovery有值，这张表没值的情况。

小程序用户通过phone来登录，wxid是来关联用户和小程序的，role_type是角色，可以通过改wxid来改登录的角色（businessType）

# bd_recovery

回收公司表，businessId就是custId，可以通过sys_user_cust的custId查询userId;

门店、运力、回收公司表的ID就是custId，也是businessId



# hs_recovery_wallet_detail

order_id 如果订单是汽车电池订单，则查汽车电池订单表；如果是电动车电池订单，则查hs_pedlar_order表，或者hs_recovery_stock(id)
