# 标题
死前三分钟

# 标签
悬疑

# 主题


# 简介
殡仪馆化妆师江澄给逝者上妆时，能看见他们死前的最后三分钟。某一具尸体的最后三分钟里，下手的人竟是还活着的江澄自己。

# 人物
江澄｜主角
夜里给逝者化妆，手很稳。欲望：弄清自己为什么会出现在那三分钟里，并在下一名死者出现前证明自己没有杀人。不能做的事：不能把看见的三分钟告诉警察，否则下一名逝者的三分钟会变成空白。把柄：她三年前给母亲上妆时，什么都没看见。

老周｜对手
馆里的入殓师，负责接收无名尸。欲望：不让江澄把某一具尸体的脸补完整。把柄：他的工作记录里少了一具“女尸，三十岁上下”。

林峭｜关键关系
来认尸的刑侦。欲望：查清连续两起夜里的勒杀。把柄：他认得江澄的手法，因为三年前那具没被看见的尸体，妆也是这种手法。

无名女尸｜已死
脸被毁过。三分钟里下手的人用的是江澄的手。她的声音和江澄母亲很像。

# 世界
三分钟
只有上妆的人能看见，从死者瞳孔里倒放。只有画面，没有声音；时长刚好三分钟。看见的是真的，但不保证下手的人就是真凶，可能是被借用的手。

说出去的代价
把某一具尸体的三分钟告诉警察，下一具到来时会什么都看不见。

连看代价
连续给三具尸体上妆并观看，会暂时失明一昼夜。

空白
给母亲上妆时是空白。空白意味着那一次要么没有死前三分钟，要么有人先看过了。

# 大纲
读者承诺｜30000字
江澄是殡仪馆化妆师，给逝者上妆时能看见其死前最后三分钟，代价是每次断片三秒。她只想攒钱辞职。给猝死老人上妆，她看见老人藏存折，按画面找到，规则验证为真。新来的无名女尸面部被毁，她上妆时看见女人在冷库被掐死，凶手抬头——是江澄自己的脸。可当天她一直在殡仪馆，有监控和同事作证。报警等于自首，不查等于等死。她决定先确认死者身份。章末：女尸指甲缝里检出江澄的皮肤组织。读者知道能力、代价、核心矛盾：她必须在自己被当成凶手前，找到另一个“自己”。

加压蓄力｜80000字
江澄查到女尸叫林菲，十年前“永安火灾”的实习护士。林菲生前一周来殡仪馆踩点，对着江澄工位拍照。同事说昨晚看见“江澄”在停尸间加班，可江澄在家睡觉。监控里确实有她，走路姿势却陌生。警方传唤，问她为什么林菲手机里有她照片。她找师父老赵要排班表，老赵烧掉一页。她尝试对自己用能力，照镜子触摸额头，什么也看不见。殡仪馆收到匿名举报，江澄被停职。章末：她在衣柜最底层翻出一件带血黑雨衣。压力升级，替身痕迹坐实，主角被逼到墙角，第一次兑现蓄力。

第一次回报｜120000字
江澄没报警，穿黑雨衣去林菲死亡的冷库蹲守。凌晨，一个“江澄”出现，同样脸、同样疤，只是左手戴红绳。两人扭打，对方喊她“妹妹”，说“你活到现在，是因为我替你杀人”。江澄拍下对方，对方逃前留下半张永安火灾合影——上面有江澄母亲、老赵、周馆长，林菲站在后排。江澄把照片给刑警沈砚，沈砚半信半疑，但同意查火灾。第一次兑现：假江澄当面承认是双胞胎姐姐江玥。章末：江玥发来短信——“下一个是沈砚，你救不救？”对手现身，同盟建立，关系落地。

加压对质｜200000字
沈砚查档案，永安火灾烧死十一人，江澄母亲是护工，老赵是保安，周馆长是殡仪馆接收员。幸存者名单里有林菲和一个失踪婴儿。江澄逼问老赵，老赵承认：周馆长当年把江澄母亲的双胞胎女儿之一抱走，交给不能生育的夫妇，那孩子就是江玥。周馆长利用江玥接近江澄，让她成为“杀人后留下皮肤组织”的替罪羊。因果链确认：林菲查火灾真相被江玥所杀，江澄的能力被周馆长用来挑目标。冲突加码：沈砚被车撞伤，江澄被通缉。章末：周馆长来电——“想洗清，来冷库，用你的手给江玥上妆。”本卷对手与因果链锁定。

锁定结局｜260000字
江澄停止新增调查线，路径只剩一条：去冷库，在周馆长和江玥面前，用能力看江玥杀林菲的最后三分钟。她把录音笔缝进寿衣，把定位发给沈砚，约定半小时无信号就抓人。她找到母亲日记：母亲知道双胞胎，但以为另一个死了。江澄决定不杀江玥，要让她活着受审。老赵偷来殡仪馆备用钥匙，说冷库地下有周馆长存放十年的档案。结局路径锁定：江澄以化妆师身份进入，给“尸体”江玥上妆，触发能力拿证据，沈砚外围收网。章末：江玥躺在化妆台上睁眼说——“你终于来了，妹妹。”所有必须伏笔收束，只等执行。

30万裁决｜300000字
冷库里，江澄给江玥上妆，看见最后三分钟：周馆长亲手教江玥掐死林菲，并说“让江澄活成凶手”。江澄打开录音，沈砚带人破门。周馆长挟持老赵，江玥反手捅伤周馆长，自己中枪。周馆长死前，江澄握住他的手，看见他最后三分钟：他烧掉永安火灾档案，但藏了副本。林菲案闭环，江澄洗清嫌疑，江玥被捕入狱。结尾：江澄回殡仪馆上班，给下一具尸体上妆，看见自己站在母亲墓前，手里握着江玥的红绳。文末：数据好则续写“红绳篇”，数据差则在此短收尾。核心事件闭环，本卷对手有结果。
