# 标题
末世连签狂

# 标签
末世系统,末日求生,升级爽文,异能

# 主题
末世绑定签到系统，连签越强，靠日常任务从炮灰打成据点话事人

# 简介
末世首日陈陌绑定签到系统，活一天就变强。据点官要夺他签到权，兽潮压境。他必须连签不断，并查清系统为何选中他。

# 人物
陈陌｜主角
灾前是城东仓储夜班理货员，做事记清单、能熬夜。欲望：靠签到活过每一次兽潮，把妹妹陈小禾接到安全区，不当梁拓的人形电池。把柄：系统面板只有他能看见，但「签到光」在高等变异体附近会短暂外泄，被看见等于暴露异能者身份。不能做的事：不能主动中断连签（断签清空连签倍率，且 72 小时内属性冻结）；不能把系统核心权限转让或「借给」别人——规则写死，试了会反噬昏迷。

梁拓｜本卷对手
「铁闸据点」实际控制人，前物业公司片区经理，手里有民兵枪械与粮仓钥匙。欲望：把所有觉醒者编成私兵，尤其盯上能稳定变强的「签到类」能力，想据为己有或做人质榨取。把柄：他私藏了灾前「星轨试点」内部名单复印件，上面有陈陌工号；名单若公开，他劫夺觉醒者的合法性会崩。不能做的事：不能承认自己灾前就收到过试点短信，否则等于承认他知情不报、趁乱夺权。

乔安｜关键关系
据点外围侦察员，前外卖骑手，认路极快。欲望：给重伤昏迷的父亲换到净水片和抗生素，因此必须跟能搞到物资的人结盟。把柄：她曾偷偷把梁拓私藏名单拍过一张模糊照片，没敢发出去。不能做的事：不能在梁拓面前承认自己会「追踪签到光」的残影（她是低级感应觉醒，只能感觉到光曾出现过）。

陈小禾｜关键关系（前期目标，中期登场）
陈陌初中妹妹，灾变时被疏散车拉到南城临时安置点。欲望：活着等到哥哥。把柄：她书包夹层里有陈陌的工牌复印件，梁拓线人若搜到会用来诱捕陈陌。本卷 12～20 万必须确认下落，26 万前兄妹汇合或稳定通讯。

徐影｜阶段性对手 / 可转化炮灰头子
自称「猎杀者」的流浪觉醒者，持有残缺「击杀签」面板（只吃击杀，不吃存活签到）。欲望：抢陈陌的完整签到权限，补全自己的残面板。把柄：残面板每次击杀后会反噬头痛，他靠吸食「低级觉醒者的痛感」缓解——据点里已有失踪者。不能做的事：不能白天在据点内公然猎杀，会被梁拓借机清洗。

系统音｜非人
无人格旁白，只推送任务与惩罚。本卷揭示到：它是「星轨试点」遗留的民用级存活激励协议，不是神。更高层谁在收数据可留。

# 世界
签到系统（仅陈陌完整版）
每日 00:00～02:00 为签到窗。成功签到：体质/力量/感知三项随机+1～3，并发放「日礼盒」。连签天数提供倍率（7/15/30 日门槛跃迁）。断签：倍率归零，属性冻结 72 小时，已获得物品不回收。

日礼盒与任务
礼盒出消耗品、蓝图残页、武器强化石。额外「生存任务」每日三条（清尸、救援、占点、搬运），完成给积分；积分可兑「技能槽」或一次性爆发。

签到光
签到瞬间周身有半息银白光。普通人看不见；变异体与部分觉醒者能看见。光是暴露源，也是徐影追踪的饵。

变异体等级
腐行（普通尸）→ 奔犬（加速）→ 甲卫（皮硬）→ 啸潮（能聚尸）→ 领主（区域级，本卷末才正面碰一次）。枪械对甲卫以上效率骤降，需异能或特制武器。

铁闸据点规则
外墙铁闸+商超改造。梁拓发「工分粮」：干活换粮，觉醒者强制登记。未登记被抓到=没收物资或关禁闭。公开抢粮者处死，私刑由梁拓一句话定。

星轨试点（本卷级真相）
灾前市政与某科技公司做过「灾难存活激励」灰度：给部分夜班工人推送未激活协议。灾变日协议自动激活。梁拓名单来自同一批灰度列表。完整签到官只有名单里极少数人能成——陈陌是本市第一个稳定连签成功的。

# 大纲
本卷首轮 30 万字裁决；规划写到约 33 万（含数据好首段续写约 3 万）。类型锁死：系统升级爽文——每段都有可见变强、打脸、夺资源；种田不是主轴（与《半亩清田》错开）。30 万前必须：连签不毁、梁拓本卷阴谋失败、签到系统本卷级来历交清、小禾有结果、徐影残签线收束。每章 1800～2500 字。爽点节奏：约每 1～1.5 万字一次小打脸或一次升级可见回报。

# 前情
硬事实：
