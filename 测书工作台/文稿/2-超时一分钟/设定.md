# 标题
超时一分钟

# 标签
都市脑洞

# 主题
外卖骑手超时受祸，要在最后一单前找到下单害人的人

# 简介
夜班骑手陈野每单超时一分钟，就要替收货人承受一次即将发生的祸。他必须在妹妹那一单截止前，找到那个专门下单转嫁灾祸的人。

# 人物
陈野｜主角
欠着医院的钱，只跑夜班。嘴硬，不敢把妹妹的病告诉别人。不能做的事：不能主动取消一单，取消会把祸记到自己头上并加倍。把柄：妹妹陈晚的病床号和欠款短信都在他手机里。

陈晚｜妹妹
住在市三院，今晚有一台不能再推迟的手术。她不知道哥哥在替别人挡祸。欲望：活过今晚。把柄：她曾经用哥哥的账号给一个陌生人下过一单“加急”。

周衡｜对手
平台调度员，对外只用虚拟号“周先生”。以前也是骑手，用同样的超时规则救过自己的人。欲望：让系统继续替他承担后果。不能做的事：不能亲自收那一单，否则祸会回到他自己身上。

乔麦｜关键关系
同一站点的骑手，记得周衡离职前的工号。想查清为什么自己的好单全被改派。把柄：她拍过一张调度后台的照片，还没敢发出去。

# 世界
超时规则
送达超过预计时间每一分钟，骑手会替收货人承受一次本该发生的祸，持续时间等于超时的分钟数。准时送达，祸仍留在收货人身上。

取消与转单
骑手取消订单，祸记到骑手头上并加倍。把订单转给别人，祸跟着新的骑手走，原骑手会失去这段记忆里的一分钟。

最后一单
每晚只有一单被系统标成“不可改派”。那一单的收货人，是下单人真正想除掉的人。

加压对质｜200000字
加密群里全是各地骑手，规则一致：超时替祸，但送厄人能指定“最后一单”。陈野发现妹妹陈苗的名字出现在预备收货人名单里，意味着有人要把妹妹的祸转给别的骑手，或把陈野的最后一单引向妹妹。对手升级：送厄人不是一个人，而是利用平台漏洞的三人小组——前算法工程师、殡葬中介、急诊护工。他们靠提前知道灾祸赚钱，也靠骑手替祸灭证。陈野与三人第一次当面交锋，被威胁“你越查，妹妹越早进名单”。冲突加码：站点被查封，陈野被全网封号，赵虎被打伤。陈野确认因果链：下单人利用平台派单把祸转给超时骑手。

锁定结局｜260000字

30万裁决｜300000字
