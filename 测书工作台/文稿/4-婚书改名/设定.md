# 标题
婚书改名

# 标签
女频言情

# 主题
替嫁新娘发现婚书上的夫君名字每晚都会改

# 简介
替嫁新娘谢晚宁发现婚书上的夫君名字每晚都会改。她要在名字变回自己仇人之前，查出是谁在改婚书，以及这个夫君还算不算同一个人。

# 人物
谢晚宁｜主角
替姐姐出嫁。欲望：在名字变成仇人霍谨之前离开或拆掉婚书，同时弄清夫君每晚失去的那段记忆还在不在。不能做的事：不能烧毁婚书，烧毁会让当夜的夫君消失。把柄：她手里有姐姐没来得及交出去的半页婚书。

承宴｜夫君
白日是温吞的世子，夜里会忘记自己白天答应过的事。欲望：留住一个不会在天亮后消失的名字。把柄：他胸口有一道和婚书同样的墨痕，自己看不见。

霍谨｜对手
谢晚宁的仇人，也是原先定下的夫君。欲望：把名字改回去，让这桩婚重新成为他的。不能做的事：不能亲手改婚书，只能让写书的人改。

写书人顾娘｜关键关系
城里最后还能写“活婚书”的人。欲望：把每一夜改名的代价记回雇主身上。把柄：她欠霍谨一条命。

# 世界
活婚书
名字写上去的那个人，当夜就是夫君。名字被改掉后，旧夫君会失去这一夜的记忆，但身上的墨痕还在。

改名时刻
每天子时改一次。若连续七夜改成同一个人，名字就会定死，不能再改。

烧毁
烧毁婚书不会解除婚姻，只会让当夜这个名字的人从城里消失到天亮。

# 大纲
读者承诺｜30000字
谢家庶女谢晚宁被嫡母推上花轿，替嫡姐嫁进传言"新郎已死"的裴家三房。她要三件事：活着出裴家、查清父亲通敌冤案的真正告发人、弄明白自己嫁的到底是谁。第一夜她掀开婚书，"裴砚"两个字当着她的面渗成"裴砚舟"。阻碍是裴家规矩：新妇碰婚书即为魇镇，喊出去就得进祠堂。失败代价是婚书一响，她连谢家女的身份都保不住。她当场试规则：用剪刀刮、用烛火烤、抄一份副本，墨迹照旧自己走——一夜只改一次，天亮前定形，且只有婚书持有人看得见。她把第一夜的名字记在枕下。

- [ ] 白天的丈夫认不出她夜里写的字，她确认"名"与"人"是两码事｜30000字

加压蓄力｜80000字
她把七日名字全记下来：裴砚、裴砚舟、裴砚山、裴砚亭……每一个都对得上裴家祠堂里的一块牌位——全是死人，且按死亡先后倒着往回走。压力层层加码：婆母装聋，管家盯她枕头，嫡姐来信勒索她"替嫁的把柄"，裴家二房开始往她房里塞"镇魇"的香灰，准备拿她顶罪。她不敢喊，只能装作怕鬼。她借送汤混进祠堂抄牌位，发现名单第七个名字是"裴崇山"——活着的裴家家主，也是当年带兵查抄谢家、亲手递上父亲罪状的人。她同时发现白天的丈夫记得的事，一夜比一夜少。
- [ ] 七日名字与祠堂牌位一一对上，倒数第七个是活人裴崇山｜80000字
- [ ] 嫡姐勒索信到，二房开始布局把"改婚书"栽到她头上｜80000字

第一次回报｜120000字
她不再被动等名字改，改用婚书自己的规矩反击：把自己的血混进墨里，在"裴砚舟"旁边写下"谢晚宁"三个字。天亮前婚书裂了一道缝，两个名字并列撑着，那一夜名字没换成。这是第一次明确兑现——她证明了改名字的人用的是裴家祠堂"续命香"烧出的墨，也证明规则可以被顶回去。代价是裴砚当晚第一次在夜里开口，说"你别写你的名字，写上去就下不来了"。他承认自己一直在，只是名字被一层层盖住。两人结成同盟：她替他守名，他替她查谢家案。
- [ ] 血写"谢晚宁"截断换名，婚书开裂，规矩第一次被顶回｜120000字
- [ ] 裴砚夜里开口，承认被压名多年，二人结盟｜120000字

加压对质｜200000字
顺墨查人，一路查到祠堂守香的老仆裴忠，再往上牵出裴崇山。因果链对上：当年谢家手里有半份"承名契"，裴崇山要另一半，于是告发谢家通敌，灭门夺契。如今他把裴砚的名字一夜一夜往上盖，是想把亲儿子挤成"从没生过"，好让自己顶上婚书，承下裴家气运。冲突加码到当面：裴砚的名字开始被人遗忘，连谢晚宁自己写下的字也在褪色，仆妇问"三房什么时候有过三郎"。嫡母带着嫡姐登门赴宴，当众指认她是替嫁，要求裴家写休书，休书上夫君那一栏，空着。
- [ ] 祠堂对质裴忠，拿到续命香墨与谢家旧案的账册｜200000字
- [ ] 嫡母当众揭替嫁，裴崇山逼她签下"无名休书"，裴砚被众人遗忘｜200000字

锁定结局｜260000字
她把婚书对着灯看透，终于看清被七层墨盖住的第一行：最初的名字只有一个，是裴砚的，下面压着谢晚宁母亲的手印——这桩婚约从头就是谢裴两家的"双名契"，必须两个名字同时在册才算婚，缺一个，契就吃人。裴崇山要的是把裴砚挤掉、自己填进"夫君"那一栏。解法也定了：满契。让七个名字在同一夜被七个活人各自认领，婚书写满，再无人能落笔。路径锁死，不再新增必须解释的伏笔：只剩一件事——第七夜月晦，祠堂，赶在最后一笔之前。
- [ ] 查出婚书第一行原名与母亲手印，"双名契"真相与解法确定｜260000字
- [ ] 裴砚彻底被遗忘，世上只剩她一个人记得他的名字｜260000字

30万裁决｜300000字
第七夜祠堂。裴崇山执笔要落下自己的名字，谢晚宁先一步把七份认领按在婚书上：族老、仆妇、裴忠的遗供、嫡母被账册逼着按的手印——七个死人名字各有活人认领，契满，笔落不下。裴崇山强行下笔，墨回涌上他手背，婚书上"夫君"一栏写出的竟是他自己的名字，当场反噬而亡。裴砚的名字回到第一行，天亮后所有人重新记得三郎。谢家通敌案凭账册翻覆，冤名洗净；改婚书的人是裴忠，受裴崇山指使，已有结果。闭环收束，本卷对手死透。若数据好，下一卷写裴砚"承名"后遗症与裴家二房反扑；若数据平，即以归名、烧契、出府短收尾。
