# 深空补丁·直接写稿

专书技能。口径仍服从工作台根目录 `测书思路.md` 的字数、30 万裁决、在产槽；**唯一例外**：本书正文由本技能在 Cursor 内直接写入文稿，**不**走豆包粘贴。

文稿根：`D:\A-work\hao\测书工作台\文稿\9-深空补丁\`

| 文件 | 用途 |
| --- | --- |
| `设定.md` | 人物、世界、全书大纲、伏笔、前情（L2 滚动记忆写这里） |
| `写稿台账.md` | 总脊卡（L0）、当前段纲（L1）、写稿状态（防工作台覆盖设定时冲掉） |
| `正文/第XXX章-章名.txt` | 单章正文 |
| `正文/全书.txt` | 全书串联 |

禁止：把 500 万大纲、全书聊天记录、全部人物百科一次塞进上下文；禁止另拆 `设定/` `大纲/` `伏笔/`；禁止未过段末对账就开下一段；禁止数据差时因已有 500 万规划强行续写。

---

## 何时读什么

每次开写前，按顺序读：

1. `写稿台账.md` 的 `# 总脊卡`（L0）
2. `写稿台账.md` 的 `# 当前段纲`（L1）
3. `写稿台账.md` 的 `# 写稿状态`
4. `设定.md` 的 `# 前情`（硬事实 / 前情 / 人物状态 / 最近三章）（L2）
5. 上一章正文末约 500 字（L4）；若无章则写开篇
6. 只挑本章用到的人物、世界规则、未收 must、残响尺状态（L3）

需要核对里程碑时，再翻 `设定.md` `# 大纲` 里**当前字段**那几段，不要通读全书大纲。

---

## 决定下一步（每次用户说续写/写章时）

读 `写稿台账.md` `# 写稿状态` 的 `已完成章数`、`through`、`下一动作`：

| 条件 | 动作 |
| --- | --- |
| 尚无完整总脊卡或当前段纲 | 先补 `写稿台账.md`，不写正文 |
| 有章改稿待重整 | 先重整该章摘要进 `设定.md` 前情，再写新章 |
| `已完成章数>0` 且能被 6 整除，且 `through < 已完成章数` | 先做「完整前情」 |
| `已完成章数>0` 且能被 3 整除，且 `through < 已完成章数` | 先做「变化清单」 |
| 累计字数刚跨过本段终点（如 3/8/12/20/26/30 万等字段界）且未对账 | 先做「段末对账」 |
| 累计字数≥30 万且未裁决 | 停笔，请用户按数据裁决；数据差短收尾，数据好先换台账里下一段 `# 当前段纲` |
| 否则 | 写下一章正文 |

用户若说「连写 N 章」：同一回合最多连写 **3 章**，然后必须停下来做变化清单或前情（取决章节数），更新设定后再继续。禁止一回合刷十几章。

---

## 写一章正文

1. 拟定本章目标：贴合台账 `# 当前段纲` 下一个未完成里程碑；**本章至少轻触四股贯穿线之一**。
2. 正文 1800～2500 字（目标 2100～2300）。超出或不足先改本章。
3. 硬约束：
   - 硬事实只信 `设定.md` `# 前情`；不得改已 closed 的 must
   - 未点名伏笔不揭穿；点名要收的本章落地或明显推进
   - 残响尺：写清持有/轮值/争夺；禁止万能武器；禁止绑死威慑
   - 系统：只给故障树与验证方向，禁止直接发成品黑科技
   - 本段若已过「锁结局」字数：禁止新开 must
4. 落盘：
   - 写入 `正文/第XXX章-<章名>.txt`（XXX 三位编号）
   - 文件内容格式：

```text
标题：章名

正文……
```

5. 追加到 `正文/全书.txt`（章间空一行）。
6. 更新 `写稿台账.md` `# 写稿状态`：已完成章数 +1，累计字数，下一动作，残响尺，四股线一句。
7. 若用户只要一章：停。若连写：继续直到满 3 章或触达清单/前情条件。

不合格：一章 <1800 或 >2500；跑出当前段纲；系统发成品；残响尺开挂；四股线整段失踪。

---

## 每 3 章：变化清单（不写正文）

根据最近三章正文，整理后写回：

- `设定.md` `# 前情`：最近三章摘要（各 80～120 字）、硬事实、人物状态
- `设定.md` `# 伏笔`：open/closed 对齐
- 新人物/规则/地点/道具：写入设定对应块，或标待确认
- `写稿台账.md`：`through` = 已完成章数；`下一动作` = 写下一章（若同时满 6 章则=完整前情）

---

## 每 6 章或重大转折：完整前情（不写正文）

重写 `设定.md` `# 前情` 整块（约 1500 字内），并更新台账 `through`：

- 硬事实、前情叙述、人物状态、未收伏笔、最近三章
- 重大转折（静默会、物种条约、拆按钮、遗迹星正名、归零等）即使未满 6 章也先重写

---

## 段末对账（约每 10 万字字段界）

未通过对账不得开下一段。结果写入台账 `# 写稿状态` 的「段末对账」行，并必要时替换 `# 当前段纲`：

- [ ] 本段里程碑是否完成
- [ ] 四股线本段各推进了什么
- [ ] 残响尺状态是否与硬事实一致
- [ ] 本段 must 是否 closed 或延期到标注字数
- [ ] 下一段：先写好新 `# 当前段纲` 再写正文

30 万处额外检查：科学锁来源、沈鸦结果、能源补丁/净室、十年缓冲是否闭环。
