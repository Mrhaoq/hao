# 健身房打印版 · 训练清单

> 82 kg · Recomp · 4+2 周期  
> 配套：[减脂历程.md](./减脂历程.md) 第五节

**当前建议：先跑 3 天 PPL 1–2 个完整 4+2 周期，恢复良好再升 4 天。**

---

## 周期速查

| | 增肌期（4 周） | 减脂期（2 周） |
|--|----------------|----------------|
| 力量 | 按下方计划 | 同计划，重量降 5–10% |
| 有氧 | 不做 | 练后 20–25 min **或** 中午 30 min（二选一） |
| 蛋白 | ≥170 g | ≥190 g |

**加重规则：** 主项连续 2 次练满 rep → 下次 +2.5–5 kg

---

## 普通健身人群 · 速查

| 项目 | 普通人最优区间 |
|------|----------------|
| 力量频率 | 每周 **3–4 次** |
| 单次时长 | **60–75 min**（含热身） |
| 5–6 次/周 | ❌ 多数人非更优 |
| 增肌期有氧 | 不做或极少 |
| 减脂期有氧 | 3–4 次 × 20–30 min |

## 休息日指南

| 活动 | 增肌期 | 减脂期 |
|------|--------|--------|
| 完全休息 | ✅ 累了就用 | ✅ 累了就用 |
| 散步 20–30 min | ✅ 推荐 | ✅ 推荐 |
| 拉伸 / 泡沫轴 | ✅ | ✅ |
| 爬坡 / HIIT | ❌ | 可选轻松爬，不必须 |
| 再练力量 | ❌ | ❌ |

**步数目标：** 每天 6000–8000 步（通勤、饭后走都算）

## 训练日程 · 最优（方案 D）

> **15:30 练前餐 → 18:20 练 → 20:00 练后正餐** · 18:40 公司晚饭窗口跳过

| 时间 | 内容 |
|------|------|
| 15:30–16:00 | 练前餐：酵母 1 勺 + 香蕉 + 面包 1 片 |
| 18:00–18:10 | 下班 → 公司健身房 |
| 18:20–19:30 | 力量（按 Day 表） |
| 19:30–19:50 | 有氧 20 min（仅减脂期） |
| 19:50–20:05 | 淋浴 → 回家 |
| 20:05–20:30 | **练后正餐**：鸭腿饭 + 卤蛋 + 杂蔬 |
| 20:30 | 乳清 1 勺 + 肌酸 |
| **22:30 前** | 躺床 |

18:40 仍在工位 → 最多补 1 蛋/半根香蕉，不吃正餐

## 备选 · 方案 A（没法练后吃饭时）

18:40 正餐 → 20:00 练 → 23:00 睡 · 练后只补粉

## 加班弹性

| 下班 | 怎么办 |
|------|--------|
| ≤19:00 | 标准练，20:00 开练 |
| 19:00–19:30 | 精简练 45 min，20:30 开练 |
| 19:30–20:30 | 超精简 30 min 或休息 |
| **>20:30** | **跳过，不熬夜补练** |

**每周目标：凑满 3 练（腿→推→拉），日期随意，不死守周一三五。**

精简练：腿=腿举+弯举+臀桥 · 推=卧推+推举+侧平举 · 拉=下拉+划船+面拉

加班周减脂：午休散步/爬坡 20 min 作备份
