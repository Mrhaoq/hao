# 07 · 院内订单详情

## 1. 何时打开

列表 / 跟进订单情况等统一规则：

```text
orderType === 1（院内护工）且 orderTag ∉ [2, 8]
  → hospitalDetail.open(row)
否则
  → 通用 Detail.open(...)
```

- `orderTag` 为 2 / 8：按「院外化」处理，进通用详情（可带 isGrab）
- 函数示例：`order/index.vue` 的 `toDetail`；跟进 `order-details.vue` 的 `toDetail`

---

## 2. 与通用详情对比

| 维度 | 通用 `detail` | 院内 `hospitalDetail` |
|------|---------------|------------------------|
| 详情 API | 71408 / 61783 / 69180 | 固定 **`api11595`**（带 orgId/tenantId/userId） |
| 布局 | 多卡片栅格 | 表格分区 `detail.vue` |
| 头部操作 | 改价/改单/派单/续约/结束/取消/转池等 | **仅刷新 + 联系管理员 + 联系阿姨** |
| 抢单/接单池 | 有 | **无** |
| 合同/支付码/财务改价 | 有 | **无**（金额概况只读） |
| 操作记录 | OrderRecord | 同组件，可 `hideTitle` |
| 评价 Tab | 有 | 有（EvaluationPanel） |

---

## 3. 结构

```text
el-drawer ~95%
├─ header：标题 + 刷新 / 联系管理员 / 联系阿姨
└─ tabs
   ├─ base：detail.vue 表格块 + OrderRecord
   └─ evaluation：EvaluationPanel
```

`open(row)` → 赋值 → `init`：`getData` + 管理员/阿姨列表。

刷新：`getData` + `detailRef.getEscortOrderFeeVO`。

### detail.vue 区块

订单概况 → 被照护人 → 套餐信息（含护理员行）→ 其他费用项 → 联系人 → 知情同意书链接。

---

## 4. 联系能力

与通用详情同源 IM 链路：

- 管理员列表：`api61631`
- 阿姨列表：`api61799`
- 腾讯账号：`api59615`
- 发任务：`api57857`

受 `showOperation` 控制（公共池下院内详情也只读）。

---

## 5. 注意

- 院内详情**没有**四宫格派单 / AssignerDrawer；护理员信息在套餐表展示
- 从接单池下的单一般不会是院内自营进 hospitalDetail；若标签异常需核对 `orderType`/`orderTag`
- 审批状态等可能在表格项中只读展示（如 processStatus）
