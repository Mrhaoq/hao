## 1. 两种列表模式

| 模式 | 判定 | 标题 | 可操作 |
|------|------|------|--------|
| 订单管理 | `isPublic === false` | 订单管理 | 详 / 派 / 续 / 转 / 分享 / 导出 / 新增 |
| 公共池 | `getQueryString("isPublic")==="true"` 或 `props.isPublic` | 订单公共池 | 仅「详」「分」；详情 `showOperation=false` |

判定代码：

```ts
const isPublic = getQueryString("isPublic") === "true" || props.isPublic;
```

嵌入选择抽屉时：`useinSelectDrawer` 会隐藏工具栏导出/部分操作，并可 `forceListMode`。

## 2. 列表数据

| 模式 | 函数 | URL |
|------|------|-----|
| 普通 | `api61775` | `POST /organization-admin/admin/pageGridOrderList` |
| 公共池 | `api69156` | `POST /organization-admin/admin/pagePoolOrderListWithSensitive` |

- 参数组装：`getRequestParams()`
- 支持排序、筛选、分页；卡片模式另有 `handleLoadMore` 加载更多
- 局部刷新：`refresh(item)` 按 `orderId` 再查并写回 `refreshData`

## 3. 搜索与列

### 3.1 搜索字段（`searchConfig`）

| 字段 | 公共池 | 订单管理 |
|------|--------|----------|
| `searchKey` | ✅ 占位「订单号」 | ✅ 订单号/姓名/手机号 |
| `orderTypes` | ❌ | ✅ 多选 |
| `orderTags` | ❌ | ✅（非 grab 场景） |
| `orderUserName` | ❌ | ✅ |
| `orderStatusList` | ❌ | ✅ |
| `serviceStartTime` / `serviceEndTime` | ❌ | ✅ daterange |
| `orderCreateTime` | ❌ | ✅ → Start/End |
| `sources` | ❌ | ✅ |
| `carerHospitalId` | ❌ | ✅ 派单医院（医院列表 API） |

列筛选映射 `columnMapFilter`：如 `orderType→orderTypes`、`orderStatus→orderStatusList`。

### 3.2 列差异

公共池隐藏：销售人员、派单院点/服务人员、客户星级、来源；`pushTime` 标题改为「下单时间」。

## 5. 行操作（`#action` / 卡片）

| 操作 | 条件 | 实现 |
|------|------|------|
| 详 | 始终 | `handleView` → `toDetail(row)` |
| 派 | `!isPublic` 且 `orderTag !== 1` | `send-order-btn`，`@confirm=refresh`；按钮自身还要求 `exceptionOrderList` 含「未派单」或抢单态 |
| 续 | `!isPublic` | `customer-follow-btn`（内部另有状态条件） |
| 转单（标签为院内自营时） | `authTransfer && orderTag===1` | `customer-turn-btn` |
| 更多·转接单池 | `row.showTransferGrabPool` | 同上 |
| 更多·分享订单 | `!isPublic` | `ExecuteTaskDrawer`，类型 `order` |
| 分 | `isPublic` | 分享类型 `orderPool` |
| 批量分享 | 勾选行 | `handleBatchShare` |

`authTransfer`：白名单接口 `api69164`（转移订单进池权限）。  
`isGrabOrg`：`api72392` 当前 org 是否在抢单机构列表，`provide('isGrabOrg')`。

## 6. 打开详情分流 `toDetail`

```text
toDetail(row, isGrabValue?)
  ├─ orderType === 1 且 orderTag ∉ [2, 8]
  │     → hospitalDetailRef.open(row)     // 院内自营
  └─ 否则
        → detailRef.open(row, isGrabValue) // 院外 / 院内非自营标签
```

- 组件挂载：`<Detail :showOperation="!isPublic" />`、`<HospitalDetail :showOperation="!isPublic" />`
- `@close` → `refresh` 刷列表行

### Mitt：`OPEN_ORDER_DETAIL`

```ts
handleOpenOrderDetail({ orderId, isOrderPool }) {
  getOrderDetail({ orderId }) // /carer-platform/carer/order/queryOrderDetail
  toDetail(res.data, isOrderPool)
}
```

建单成功「查看订单」会带上 `isOrderPool`，保证接单池单按池态打开。
