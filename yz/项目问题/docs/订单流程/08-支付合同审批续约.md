## 1. 支付二维码

文件：[`payQrcode.vue`](../../src/views/order/detail/components/payQrcode.vue)

### 显示

- 父级：`record.payResultDTO?.waitPaid` 有值才挂载
- `showOperation===false` → Empty「暂不支持查看」

### 拉码与展示

- `api3666` 线上二维码支付申请（`payChannel:3, paySource:2, payPort:2`）
- 展示待付金额；点击卡片放大（被照护人脱敏、地址/时间/套餐/价格）

### 轮询与停止

- watch 待付变化拉码；可能伴随详情轮询
- 详情 `onClose` / unload → `payQrcodeRef.stopPolling()`

## 3. 审批流

抽屉：[`approvalDrawer.vue`](../../src/views/order/detail/components/approvalDrawer.vue)

- `open(processId)` → wflow  
  `GET /wflow/wflow/process/progress/{processId}/node_0`
- 展示：提交人、流程名、编号、表单字段、审批人

### 触发点

| 场景 | 触发字段 / 入口 | 发起接口（若新建） |
|------|-----------------|-------------------|
| 改总价 / 减免 | `orderDiscountRecordDTOS[0].processId` 或提交 `api61887` | 改价走 61887，已有 process 则只读审批 |
| 修改服务时间 | `updateOrderServiceTimeApprovalDTO.processId` | 改单组件内 |
| 取消服务 | `cancelOrderApprovalDTO.processId`；或 `api61863` 发起 | 直接取消 `api853` |

财务区减免编辑与改总价按钮共用同一套判断。

## 4. 续约

### 4.1 列表 / 详情按钮 `customer-follow-btn`

显示条件：

```text
orderType !== 1
&& orderStatus ∈ [2, 3, 4, 8]
&& !(status===8 && 结束时间 + 6小时 < now)
```

详情模板另挡：`orderStatus !== 9`。

点击：`renewalRef.open(row)`。

### 4.2 `renewal.vue` 提交

1. 打开时 `getOrderDetail({ orderId })` → `/carer-platform/carer/order/queryOrderDetail`
2. 校验：结束时间 > 开始时间，且 ≥ 原 `orderFinishServiceTime`
3. `updateRenewalOrderPackageV2`：

```text
{ orderId, subOrderId, orderStartServiceTime, orderFinishServiceTime, carerId }
POST /organization-admin/org/admin/updateRenewalOrderPackageV2
```

4. 成功 `emit('refresh'/'confirm')` → 父刷新

### 4.3 与建单抽屉续约模式

CreateOrder 传入 `orderId` 时也可走 `updateRenewalOrderPackageV2`（跟进侧续约建单形态），与按钮组件路径不同、接口相同。
