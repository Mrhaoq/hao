# 05 · 详情信息区块

源码：`src/views/order/detail/components/*`

返回：[总目录](./README.md)

Tab「订单基础信息」自上而下卡片；「评价」为独立面板。

---

## 总览顺序

Contract → BaseInfo → Patient → PayQrcode（有待付）→ CustomerInfo → RemarkInfo → FinanceInfo → PayRecord → AssignInfo → FeedbackInfo → DemandForm → InterviewRecord → OrderRecord

---

## 1. Contract 合同

文件：`contract.vue`

| 项 | 说明 |
|----|------|
| 只读空态 | `!showOperation` → Empty「暂不支持查看」 |
| 已签 | 有 `signedFileUrl` → 预览 PDF |
| 未签 | 太阳码 `api3239`；短链 `api32205`；分享 `api57857` taskType3 |
| 轮询 | 每 3s `api61783` 直到出现 `signedFileUrl` |
| 停止 | 详情关闭 / unload → `stopPolling` |

URL 来自 SaaS：`contractQrcodeUrl` / `agreementQrcodeUrl`（经纪 serviceType 等分支）。

---

## 2. BaseInfo 基本信息

- 展示：订单号、类型、状态、星级、来源、签约时间、服务时间、天数等
- 编辑：服务时间在允许状态下可点改（受 `showOperation`、审批态影响）
- 改时间可能触发审批（`updateOrderServiceTimeApprovalDTO`）

---

## 3. Patient 被照护人

- 查看 / 编辑（`showOperation`）
- 保存类接口：`api61887` 等与订单编辑同源能力

---

## 4. PayQrcode 支付二维码

文件：`payQrcode.vue`

| 项 | 说明 |
|----|------|
| 挂载 | 父级 `v-if="payResultDTO.waitPaid"` |
| 只读 | `!showOperation` → Empty |
| 拉码 | `api3666`（payChannel:3, paySource:2, payPort:2） |
| UI | 待付金额；点击放大（脱敏被照护人、地址/时间/套餐） |
| 停止 | `stopPolling` 由详情关闭调用 |

详见 [08](./08-支付合同审批续约.md)。

---

## 5. CustomerInfo 客户信息

- 联系人、服务地址、技能/陪诊标签
- 状态 2/3/4 且 `showOperation` 可编
- inject `isGrab`（部分护理员展示逻辑，现多注释）

---

## 6. RemarkInfo 备注

- 状态 2/3/4 且可操作时可编辑

---

## 7. FinanceInfo 财务

- 只读：首付比例、合同金额、首付款、已付/待付、减免、节假日、退款
- 减免编辑图标：同「改总价」条件 + `showOperation` → `api61887` / 审批

---

## 8. PayRecord 支付流水

- 按 `orderId` 拉支付/退款流水表
- 刷新随详情 `refersh`

---

## 9. AssignInfo 指派信息

- 服务人员指派列表、档期、联系
- 接收 `:isGrab`，影响档期/跟进抽屉行为
- 派单成功后父 `assign()` → `getAssignInfo` 刷新

---

## 10. FeedbackInfo 反馈信息

文件：`feedbackInfo.vue`

| 项 | 说明 |
|----|------|
| 列表 | `api71424` 分页；反馈类型枚举 order/enumList |
| 派单入口 | `expose.sendOrders` → 打开 AssignerDrawer（详情抢单派单） |
| 反馈提交 | Dialog → `api71420` |
| 关闭抽屉 | `@close` → 父 `refersh` |

AssignerDrawer 列表：`api71436`；派单：`api71632`；联系：`api73224`。详见 [04](./04-详情头部操作详解.md)。

---

## 11. DemandForm 需求单

- 列表；`showOperation` 时可「添加需求单」
- 添加组件：`addDemandForm.vue`

---

## 12. InterviewRecord 面试记录

- 条件展示创建面试：`!unref(isGrab)` 且业务规则 + 权限
- 接单池态隐藏创建按钮
- 列表接口：`api71620` 等

---

## 13. OrderRecord 操作记录

- 按 `orderId` 展示操作日志
- 院内详情复用时可 `hideTitle`

---

## 14. EvaluationPanel 评价 Tab

- `orderId` 维度评价数据；头部刷新在 evaluation tab 只刷本面板

---

## 刷新依赖小结

| 动作 | 影响区块 |
|------|----------|
| 详情 refersh | 几乎全部 base 子模块 |
| 派单成功 | AssignInfo + Feedback |
| 合同/支付轮询 | Contract / PayQrcode 自身 |
| 抽屉关闭 | 停合同与支付轮询 |
