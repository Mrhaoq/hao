## 1. Mitt 事件

| 事件常量 | 发出方 | 载荷 | 消费方 |
|----------|--------|------|--------|
| `OPEN_ORDER_DETAIL` | create-order 成功「查看订单」 | `{ orderId, isOrderPool? }` | order/index、grabOrder、my-clue、customer-follow、index-simple |
| `ORDER_CREATED` | create-order `completeOrderSuccess` | — | 跟进页订单面板等 |
| `SEND_MESSAGE` / `SHORTCUT_MENU` | 阿姨侧下单 | `isOrderPool`、`auntInfo`、`orderPositionChecked` 等 | customer-follow 打开菜单 |
| `SELECT_AUNT` | 阿姨列表选人 | auntInfo | 改单/建单选阿姨 |
| `ORDER_CREATED` 等其它 | — | — | 见 `MittEnum` |

常量文件：`src/views/system-manage/customer-follow/constant/enum.js`

## 6. 权限点（前端）

| 权限码 | 场景 |
|--------|------|
| `view_export_order_list` | 导出列表按钮 |
| `export_order` | 导出下拉 |

其它按钮多依赖业务字段 + `showOperation`，而非统一 permission 指令。

转池能力还依赖 `api69164` 白名单 → `authTransfer`。

---

## 7. URL Query / Props

| 参数 | 作用 |
|------|------|
| `isPublic=true` | 订单公共池列表 + 详情只读 |
| `isGrab=true` | 详情抢单态（接单池页 ensureDetailQuery） |
| `showOperation=true` | 详情可操作 |
| `isGrab` / `showOperation` props | Detail / HospitalDetail 组件 props |
| `useinSelectDrawer` | 选择抽屉嵌入订单列表 |
| `tab=base\|evaluation` | 详情 Tab（useTabRoute） |
