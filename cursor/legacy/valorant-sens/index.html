无畏契约灵敏度工坊

用爆头点射测手感，生成可直接填进游戏的腰射灵敏度。甩枪左键开火，打头部才算爆头。

使用前检查

  • Windows 指针速度设为 6/11（中间档）
  • 关闭「提高指针精确度」（鼠标加速）
  • 无畏契约开启原始输入缓冲
  • 鼠标驱动 DPI 与下方填写值一致
  • 请在电脑上测（需要鼠标锁定）

建档

习惯标签只影响起始区间，最终灵敏度由爆头点射结果收敛。
