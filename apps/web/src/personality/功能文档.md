# 多维度人格测评 — 功能文档

路径：`/personality/`  
线上：https://cursor-personality-test.pages.dev/personality/  
类型：A 打开即用（本机 `localStorage`，无后端）

本文按当前源码整理（`apps/web/src/personality/`），描述真实行为，不是设计稿。

## 这是什么

五档 Likert 量表的自研多维度人格倾向测评：16 型、Step II 子维度、A/T、大五、九型、DISC、霍兰德。完整版约 220 题，快速版约 115 题（M1+M4）。结果可导出 JSON / 打印 PDF / 复制 Markdown。

非 MBTI® 官方产品，不能替代心理咨询。

## 页面与主路径

三个视图：首页（选完整/快速、导入导出）、答题、结果（雷达图 + 解读）。题库 `data/questions.ts` 动态 `import()`，不进首页 bundle。

## 存储

键 `hao.personality.v1`。读取时若无新键则读 `personality_test_v1`。清除时两个键都删。

## 限制与已知缺口

- PDF 走浏览器打印弹窗，微信内可能失败
- 题库大，首次打开测评页会加载独立 chunk
- 离线单文件 `personality-test.html` 已归档，不再作为主开发面
