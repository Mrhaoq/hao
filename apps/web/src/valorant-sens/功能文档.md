# 无畏契约灵敏度工坊 — 功能文档

路径：`/valorant-sens/`  
线上：https://cursor-personality-test.pages.dev/valorant-sens/  
类型：A 打开即用（本机 `localStorage`，无后端）  
存储键：`hao.valorant-sens.v1`

本文按当前源码整理（`apps/web/src/valorant-sens/`），描述真实行为，不是设计稿。完整算法与关卡说明仍可对照 `cursor/legacy/valorant-sens/功能文档.md`。

## 这是什么

给无畏契约玩家测出一档可直接填进游戏的腰射「灵敏度：通用」。网页画布模拟 yaw=0.07，用爆头点射收敛后再 A/B。同时提供跨游戏腰射换算、DPI 等效表、±10% 微调和本机历史。

## 在站点中的位置

catalog `id`：`valorant-sens`；路径 `/valorant-sens/`；`live`；顶栏可回 `/`。有效测试必须在电脑浏览器（Pointer Lock）。

## 页面与主路径

四个 Tab：生成向导、测试画布、结果、工具箱。页脚常驻本机历史。

## 存储

键 `hao.valorant-sens.v1`，含 profile / lastInputs / lastTune / finalSens / history。

## 限制与已知缺口

手机无法 Pointer Lock；网页 FOV 与游戏不完全一致；ADS / 开镜不换算。

## 可拓展

1. **未做的模式/入口**：ADS 换算、云端档案、移动端简化测法
2. **可插的存储字段**：`history` 已有；可加 `profiles[]`；不要改键名
3. **不要动的公共约定**：catalog / shell / `hao.valorant-sens.v1` / `/valorant-sens/`
4. **建议的下一步**：无。当前以手感收敛为主，换算已够用
