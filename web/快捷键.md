**文本编辑快捷键：**

- **Ctrl + C**: 复制选中的内容
- **Ctrl + V**: 粘贴复制的内容
- **Ctrl + X**: 剪切选中的内容
- **Ctrl + Z**: 撤销上一步操作
- **Ctrl + A**: 全选
- **Ctrl + F**: 查找内容
- **Ctrl + H**: 查找替换
- **Ctrl + Shift + V**: 粘贴纯文本
- **Ctrl + Shift + Arrow Keys**: 按单词选择文本
- **Ctrl + Arrow Keys**: 按单词移动光标
- **Ctrl + Backspace**: 删除光标前的整个单词
- **Ctrl + Delete**: 删除光标后的整个单词
- **Ctrl + Home**: 移动光标到文档开头
- **Ctrl + End**: 移动光标到文档末尾

**应用程序和窗口管理快捷键：**

- **Alt + Tab**: 切换应用程序
- **Alt + F4**: 关闭应用程序或窗口
- **Ctrl + N**: 创建新文档或窗口
- **Ctrl + O**: 打开文件
- **Ctrl + P**: 打印文档或页面
- **Ctrl + S**: 保存文档
- **Ctrl + T**: 打开新标签页（浏览器）
- **Ctrl + W**: 关闭当前活动窗口或标签页
- **Ctrl + Shift + N**: 创建新文件夹
- **Ctrl + Shift + T**: 重新打开最近关闭的标签页
- **Alt + Enter**: 显示所选项目属性
- **Alt + Esc**: 循环切换应用程序
- **Alt + Spacebar**: 打开应用程序系统菜单
- **Ctrl + Shift + Tab**: 向后循环切换选项卡
- **Ctrl + Tab**: 向前循环切换选项卡

**系统和文件管理快捷键：**

- **Windows 键 + D**: 显示桌面
- **Windows 键 + E**: 打开文件资源管理器
- **Windows 键 + L**: 锁定计算机
- **Windows 键 + R**: 打开运行对话框
- **Windows 键 + I**: 打开设置
- **Windows 键 + S**: 打开搜索
- **Windows 键 + M**: 最小化所有窗口
- **Windows 键 + Shift + M**: 还原最小化的窗口
- **Windows 键 + F**: 打开反馈中心
- **Shift + Delete**: 直接删除项目
- **Shift + F10**: 显示上下文菜单
- **F2**: 重命名项目
- **F3**: 打开搜索（文件资源管理器）
- **F4**: 显示地址栏下拉列表
- **F5**: 刷新窗口或页面

**截图和屏幕管理快捷键：**

- **Windows 键 + PrtScn**: 截图并保存为文件
- **PrtScn**: 复制整个屏幕到剪贴板
- **Ctrl + PrtScn**: 复制当前窗口到剪贴板
- **Windows 键 + Plus (+)**: 打开放大镜
- **Windows 键 + Escape**: 关闭放大镜
- **Windows 键 + Shift + S**: 打开屏幕截图工具

**任务管理和虚拟桌面快捷键：**

- **Ctrl + Alt + Delete**: 打开任务管理器或安全选项
- **Ctrl + Shift + Esc**: 直接打开任务管理器
- **Windows 键 + Tab**: 打开任务视图
- **Windows 键 + Ctrl + D**: 创建新虚拟桌面
- **Windows 键 + Ctrl + F4**: 关闭当前虚拟桌面
- **Windows 键 + Ctrl + Left/Right Arrow**: 切换虚拟桌面

**其他快捷键：**

- **Ctrl + Plus (+)**: 放大视图
- **Ctrl + Minus (-)**: 缩小视图
- **Ctrl + Scroll Wheel**: 缩放视图
- **Windows 键 + Period (.)**: 打开表情符号面板
