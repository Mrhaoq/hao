# 函数方法

1. `call()` - 调用一个函数，其具有一个指定的 `this` 值和分别提供的参数。

   ```javascript
   function greet(name) {
       console.log(`Hello, ${name}!`);
   }
   greet.call(null, 'Alice'); // 输出: Hello, Alice!
   ```

2. `apply()` - 调用一个函数，其具有一个指定的 `this` 值和参数提供为数组（或类似数组的对象）。

   ```javascript
   function sum(a, b) {
       return a + b;
   }
   let numbers = [2, 3];
   let result = sum.apply(null, numbers); // 结果为 5
   ```

3. `bind()` - 创建一个新函数，当被调用时将其 `this` 关键字设置为提供的值，并在调用新函数时，将给定的参数序列作为前几个参数。

   ```javascript
   function greet() {
       return `Hello, ${this.name}!`;
   }
   const person = { name: 'Alice' };
   const boundGreet = greet.bind(person);
   console.log(boundGreet()); // 输出: Hello, Alice!
   ```

4. `toString()` - 返回表示当前函数源代码的字符串。

   ```javascript
   function sayHello() {
       return 'Hello World!';
   }
   let str = sayHello.toString();
   console.log(str); // 输出函数 sayHello 的源代码
   ```

5. `valueOf()` - 返回函数对象本身，通常与 `toString()` 方法相同。

   ```javascript
   function sum(a, b) {
       return a + b;
   }
   let value = sum.valueOf();
   console.log(value); // 输出函数 sum 的源代码
   ```
