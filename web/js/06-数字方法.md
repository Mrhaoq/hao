# 数字方法

1. `toFixed()` - 将数字转换为指定小数位数的字符串表示形式。

   ```javascript
   let num = 123.456789;
   let result = num.toFixed(2); // 结果为 "123.46"
   ```

2. `toPrecision()` - 将数字转换为指定精度的字符串表示形式。

   ```javascript
   let num = 123.456789;
   let result = num.toPrecision(4); // 结果为 "123.5"
   ```

3. `toExponential()` - 将数字转换为指数表示形式的字符串。

   ```javascript
   let num = 123.456789;
   let result = num.toExponential(2); // 结果为 "1.23e+2"
   ```

4. `toString()` - 将数字转换为字符串。

   ```javascript
   let num = 123;
   let result = num.toString(); // 结果为 "123"
   ```

5. `valueOf()` - 返回数字的原始值。

   ```javascript
   let num = new Number(123);
   let value = num.valueOf(); // 结果为 123
   ```

6. `toFixed()` - 将数字转换为指定小数位数的字符串表示形式。

   ```javascript
   let num = 123.456789;
   let result = num.toFixed(2); // 结果为 "123.46"
   ```

7. `isNaN()` - 检查数字是否为 NaN（非数字）。

   ```javascript
   let num = NaN;
   let result = isNaN(num); // 结果为 true
   ```

8. `isFinite()` - 检查数字是否为有限数。

   ```javascript
   let num = Infinity;
   let result = isFinite(num); // 结果为 false
   ```

9. `parseInt()` - 将字符串转换为整数。

   ```javascript
   let str = "123";
   let num = parseInt(str); // 结果为 123
   ```

10. `parseFloat()` - 将字符串转换为浮点数。

    ```javascript
    let str = "3.14";
    let num = parseFloat(str); // 结果为 3.14
    ```

11. `Math.abs()` - 返回数字的绝对值。

    ```javascript
    let num = -5;
    let absNum = Math.abs(num); // 结果为 5
    ```

12. `Math.round()` - 对数字进行四舍五入。

    ```javascript
    let num = 3.6;
    let roundedNum = Math.round(num); // 结果为 4
    ```

13. `Math.floor()` - 返回小于或等于给定数字的最大整数。

    ```javascript
    let num = 3.9;
    let floorNum = Math.floor(num); // 结果为 3
    ```

14. `Math.ceil()` - 返回大于或等于给定数字的最小整数。

    ```javascript
    let num = 3.1;
    let ceilNum = Math.ceil(num); // 结果为 4
    ```
