# 事件循环

## 什么是进程

- 进程是一个在操作系统内部运行的程序实例，它是系统进行资源分配和调度的基本单位。进程可以创建子进程，不同进程之间资源是隔离的。

1. 程序的一次执行实例。一个进程对应一个正在执行的程序。
2. 进程是系统进行资源分配和调度的基本单位。操作系统会给每个进程分配CPU时间片进行执行。
3. 进程具有自己的内存空间。一个进程中所有变量和对象都在其地址空间内。不同进程之间的地址空间是隔离的。
4. 进程可以创建新的进程，一个进程可以fork出新的子进程。
5. 进程有自己的资源，如文件描述符表、打开的文件等。
6. 进程有自己的状态，如运行、等待、就绪等。操作系统会根据进程状态进行调度。
7. 进程间通信可以通过管道、消息队列、信号量等手段实现。

## 什么是线程

- 线程是比进程更小的执行单位，它可以提高资源利用率，实现并发编程。线程在同一个进程内运行，共享进程资源，实现了内部的并发操作。、

1. 线程是进程中的一个实体，一个进程可以分为多个线程，线程是cpu调度和分派的基本单位。

##进程和线程的区别

- 进程是操作系统资源分配的基本单位，线程是CPU资源分配和调度的基本单位。
- 一个进程可以包含多个线程，多个线程共享进程的资源，如内存、文件描述符等。
- 线程是轻量级的进程，消耗的资源远少于进程，线程创建和切换的开销小于进程。
- 线程之间可以并发执行，一个进程中的多个线程可以同时运行。
- 线程之间共享进程的所有资源，如内存、文件描述符表等，但不共享线程私有资源，如线程堆栈和程序计数器等。
- 一个线程退出不会影响其他线程和进程，但整个进程退出会终止所有线程。
- 线程通信更高效，可以直接访问共享内存完成通信，而进程通常需要通过消息队列、管道等进行通信。



## 进程和线程的作用和特征

1. 主进程（Browser Process）：
   - 作用：控制浏览器的整体运行，管理其他进程。
   - 特征：只有一个主进程，负责创建和销毁其他进程，处理用户界面的交互，包括地址栏、书签栏、菜单等。
2. 渲染进程（Renderer Process）：
   - 作用：负责页面的渲染和展示。
   - 特征：每个标签页对应一个渲染进程，相互之间是隔离的，一个渲染进程崩溃不会影响其他标签页的正常使用。渲染进程包含多个渲染线程，用于处理页面的布局、样式计算、绘制等。
3. GPU进程（GPU Process）：
   - 作用：利用GPU加速页面的渲染和绘制。
   - 特征：独立的进程，负责处理与图形相关的任务，如3D渲染、图像处理等。
4. 网络进程（Network Process）：
   - 作用：处理网络请求和数据传输。
   - 特征：独立的进程，负责与服务器进行通信，处理网络请求和响应，如HTTP请求、WebSocket等。
5. 插件进程（Plugin Process）：
   - 作用：运行浏览器插件。
   - 特征：独立的进程，用于加载和运行浏览器插件，与渲染进程隔离，提高安全性。

除了进程，浏览器还包含以下几类线程：

1. 渲染线程（Rendering Thread）：
   - 作用：负责页面的渲染和绘制。
   - 特征：每个渲染进程包含多个渲染线程，用于处理页面的布局、样式计算、绘制等。
2. JavaScript引擎线程（JavaScript Engine Thread）：
   - 作用：执行JavaScript代码。
   - 特征：负责解析和执行JavaScript代码，如V8引擎线程。
3. 定时器线程（Timer Thread）：
   - 作用：处理定时器任务。
   - 特征：负责管理定时器任务的触发和执行。
4. 事件触发线程（Event Trigger Thread）：
   - 作用：处理事件的触发和分发。
   - 特征：负责监听用户输入、网络请求等事件的触发，将事件分发给相应的线程处理。
5. 异步HTTP请求线程（Asynchronous HTTP Request Thread）：
   - 作用：处理异步的HTTP请求。
   - 特征：负责发送异步的HTTP请求并处理响应。
