# console基础使用

1. `console.log()`: 输出普通信息。
2. `console.info()`: 输出提示性信息。
3. `console.warn()`: 输出警告信息。
4. `console.error()`: 输出错误信息。
5. `console.dir()`: 以一个交互列表显示一个对象的所有属性。
6. `console.table()`: 以表格形式展示对象。
7. `console.time()`: 记录时间的开始。 ( 可以用来记录代码的执行时间 )
8. `console.timeEnd()`: 记录时间的结束。
9. `console.timeLog()`: 记录已经过去的时间。
10. `console.trace()`: 输出一个堆栈跟踪。
11. `console.assert()`: 如果条件不满足，则输出一个错误消息。
12. `console.clear()`: 清空控制台。
13. `console.count()`: 记录特定标签被调用的次数。
14. `console.countReset()`: 重置特定标签的计数器。
15. `console.group()`: 创建一个新的内联组。
16. `console.groupCollapsed()`: 创建一个新的内联组，这个内联组是默认是收起的。
17. `console.groupEnd()`: 结束内联组。
18. `console.profile()`: 开始一个JavaScript CPU分析报告。
19. `console.profileEnd()`: 结束一个JavaScript CPU分析报告。
