# 对象方法

### Object 静态方法

1. `Object.assign(target, ...sources)` - 用于将所有可枚举属性的值从一个或多个源对象复制到目标对象。

   ```javascript
   const target = { a: 1 };
   const source = { b: 2 };
   Object.assign(target, source);
   console.log(target); // 输出: { a: 1, b: 2 }
   ```

2. `Object.create(proto, [propertiesObject])` - 创建一个新对象，使用现有的对象来提供新创建的对象的 `__proto__`。

   ```javascript
   const person = {
       isHuman: false,
       printIntroduction: function() {
           console.log(`My name is ${this.name}. Am I human? ${this.isHuman}`);
       }
   };
   const me = Object.create(person);
   me.name = 'Alice';
   me.isHuman = true;
   me.printIntroduction(); // 输出: My name is Alice. Am I human? true
   ```

3. `Object.defineProperty(obj, prop, descriptor)` - 在对象上定义新属性，或修改现有属性，并返回该对象。

   ```javascript
   const object1 = {};
   Object.defineProperty(object1, 'property1', {
     value: 42,
     writable: false
   });
   console.log(object1.property1); // 输出: 42
   ```

4. `Object.entries(obj)` - 返回一个给定对象自身可枚举属性的键值对数组。

   ```javascript
   const object1 = { a: 'somestring', b: 42 };
   for (const [key, value] of Object.entries(object1)) {
     console.log(`${key}: ${value}`);
   }
   // 输出: "a: somestring" 和 "b: 42"
   ```

5. `Object.freeze(obj)` - 冻结一个对象，使其属性不可修改。

   ```javascript
   const obj = { prop: 42 };
   Object.freeze(obj);
   obj.prop = 33; // 抛出错误，在严格模式下
   console.log(obj.prop); // 输出: 42
   ```

6. `Object.keys(obj)` - 返回一个包含所有给定对象自身可枚举属性名称的数组。

   ```javascript
   const object1 = { a: 'somestring', b: 42, c: false };
   console.log(Object.keys(object1)); // 输出: ["a", "b", "c"]
   ```

7. `Object.values(obj)` - 返回一个包含给定对象自身可枚举属性值的数组。

   ```javascript
   const object1 = { a: 'somestring', b: 42, c: false };
   console.log(Object.values(object1)); // 输出: ["somestring", 42, false]
   ```

### Object 原型方法

1. `Object.prototype.hasOwnProperty(prop)` - 返回一个布尔值，指示对象自身属性中是否具有指定的属性。

   ```javascript
   const object1 = { prop: 'exists' };
   console.log(object1.hasOwnProperty('prop')); // 输出: true
   console.log(object1.hasOwnProperty('toString')); // 输出: false
   ```

2. `Object.prototype.isPrototypeOf(object)` - 用于测试一个对象是否存在于另一个对象的原型链上。

   ```javascript
   function MyObject() {}
   const myInstance = new MyObject();
   console.log(MyObject.prototype.isPrototypeOf(myInstance)); // 输出: true
   ```

3. `Object.prototype.propertyIsEnumerable(prop)` - 返回一个布尔值，表示指定的属性是否可枚举。

   ```javascript
   const object1 = {};
   object1.property1 = 42;
   console.log(object1.propertyIsEnumerable('property1')); // 输出: true
   ```

4. `Object.prototype.toString()` - 返回对象的字符串表示。

   ```javascript
   const object1 = new Date();
   console.log(object1.toString()); // 输出: Tue May 17 2022 12:55:50 GMT+0200 (Central European Summer Time)
   ```

5. `Object.prototype.valueOf()` - 返回指定对象的原始值。

   ```javascript
   const object1 = new Number(5);
   console.log(object1.valueOf()); // 输出: 5
   ```







静态方法（`Object`类方法）:

1. `Object.assign(target, ...sources)` - 用于将一个或多个源对象的可枚举属性复制到目标对象。它返回目标对象。
2. `Object.create(proto, [propertiesObject])` - 创建一个新对象，使用现有的对象来提供新对象的`__proto__`。还可以选择性地为新对象添加属性。
3. `Object.defineProperty(obj, prop, descriptor)` - 添加或修改指定对象的一个属性，并返回该对象。
4. `Object.defineProperties(obj, props)` - 添加或修改指定对象的多个属性，并返回该对象。
5. `Object.entries(obj)` - 返回一个给定对象自身可枚举属性的键值对数组。
6. `Object.freeze(obj)` - 冻结一个对象，使其属性不可修改。
7. `Object.fromEntries(iterable)` - 将键值对的列表转换为一个对象。
8. `Object.getOwnPropertyDescriptor(obj, prop)` - 返回指定对象上一个自有属性对应的属性描述符。
9. `Object.getOwnPropertyDescriptors(obj)` - 返回指定对象自身属性的描述符。
10. `Object.getOwnPropertyNames(obj)` - 返回一个数组，包含了指定对象自身所有属性的名称。
11. `Object.getOwnPropertySymbols(obj)` - 返回一个给定对象自身的所有 Symbol 属性的数组。
12. `Object.getPrototypeOf(obj)` - 返回指定对象的原型。
13. `Object.is(value1, value2)` - 比较两个值是否相同。
14. `Object.isExtensible(obj)` - 判断一个对象是否可扩展。
15. `Object.isFrozen(obj)` - 判断一个对象是否被冻结。
16. `Object.isSealed(obj)` - 判断一个对象是否被密封。
17. `Object.keys(obj)` - 返回一个包含给定对象自身可枚举属性名称的数组。
18. `Object.preventExtensions(obj)` - 阻止新属性被添加到对象，并返回该对象。
19. `Object.seal(obj)` - 防止其他代码删除或更改指定对象的属性，并返回该对象。
20. `Object.setPrototypeOf(obj, prototype)` - 设置一个指定对象的原型（即，内部[[Prototype]]属性）到另一个对象或 `null`。
21. `Object.values(obj)` - 返回一个包含给定对象所有可枚举属性值的数组。

原型方法（所有对象实例的通用方法）:

1. `obj.hasOwnProperty(prop)` - 用于判断对象自身（不包括原型链）是否具有指定名称的属性。
2. `obj.isPrototypeOf(object)` - 用于判断一个对象是否是另一个对象的原型。
3. `obj.propertyIsEnumerable(prop)` - 用于判断指定属性是否可枚举。
4. `obj.toLocaleString()` - 返回对象的本地化字符串表示。
5. `obj.toString()` - 返回对象的字符串表示。
6. `obj.valueOf()` - 返回指定对象的原始值。
