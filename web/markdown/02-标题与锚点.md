## 锚点是什么

锚点 = 页面里某个标题的「地址」。

目录链接写成：

```markdown
[点击这里](#某个锚点)
```

浏览器/预览器会滚到带这个 id 的标题处。

---

## 必须四个井号吗？

**不必。** `#`～`######` 都会生成锚点。

| 写法 | 级别 | 生成锚点 |
|------|------|----------|
| `#` | h1 | ✅ |
| `##` | h2 | ✅ |
| `###` | h3 | ✅ |
| `####` | h4 | ✅ |
| `#####` / `######` | h5/h6 | ✅ |

日报用 `####`、周报用 `##` 只是层级约定（保证大纲可读），不是语法要求。

---

## 锚点怎么自动生成

以 GitHub / 多数预览器规则为例：

1. 取标题文字（不含前面的 `#`）
2. 转小写（中文不变）
3. **去掉标点**（如 `【】（）、，。`）
4. 空格变成 `-`

示例：

```markdown
## 【前端周报】2026-7-24（郝高尚）
```

生成锚点：

```text
#前端周报2026-7-24郝高尚
```

目录应写成：

```markdown
- [7-24](#前端周报2026-7-24郝高尚)
```

---

## 显示文字不是模糊匹配

```markdown
- [7-24](#前端周报2026-7-24郝高尚)
   ↑只是显示字      ↑才是跳转目标（要精确）
```

- 方括号里写什么都行：`7-24`、`周报`、`点我`
- `#` 后面必须和标题锚点一致，**不是模糊搜索标题**

若编辑器大纲里能模糊搜到标题，那是编辑器搜索，不是 Markdown 锚点语法。

---

## 常见踩坑

| 错误 | 原因 |
|------|------|
| `-#### 标题` | `-` 变成列表，不是标题，无锚点 |
| 锚点里仍写 `【】` | 标点已被去掉，写了反而跳不过去 |
| 标题改了目录没改 | 锚点跟着标题变，目录会失效 |
| 同文件两个相同标题 | 第二个锚点常变成 `xxx-1`，易乱 |

### 自定义短锚点示例

下面用 HTML `id` 固定短锚点（不依赖去标点规则）：

链接：

```markdown
- [7-24](#d-2026-7-24)
```
