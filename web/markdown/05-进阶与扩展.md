## 自定义锚点 id

不想记「去标点后的长锚点」时，自己指定短 id。

### 方式 A：标题里包 span（兼容较好）

```markdown
#### <span id="d-2026-7-24">【前端日报】2026-7-24（郝高尚）</span>

- [7-24](#d-2026-7-24)
```

#### <span id="d-2026-7-24">示例标题（点下面可跳回）</span>

试跳：[短锚点 d-2026-7-24](#d-2026-7-24)

### 方式 B：标题上方单独锚点

```markdown
<a id="w-2026-7-24"></a>
#### 【前端周报】2026-7-24（郝高尚）

- [7-24](#w-2026-7-24)
```

### 方式 C：部分扩展语法（GitHub 不一定支持）

```markdown
## 标题 {#custom-id}
```

Typora、部分静态站点生成器支持；以你实际预览环境为准。

## 用 HTML 增强

Markdown 里可混写 HTML：

```html
<br>
<strong>加粗</strong>
<span style="color:#c23">注意色</span>
<details>…</details>
```

换行：`第一行<br>第二行`

## 折叠区块

GitHub 支持：

```html
<details>
<summary>点击展开：联调清单</summary>

- 接口 A
- 接口 B
- 边界：白名单判断

</details>
```

## 平台差异速查

| 能力 | GitHub | VS Code/Cursor 预览 | Typora |
|------|--------|---------------------|--------|
| 标题自动锚点 | ✅ | ✅ | ✅ |
| 任务列表 | ✅ | ✅ | ✅ |
| 表格 | ✅ | ✅ | ✅ |
| `{#id}` 自定义 | ❌/弱 | 看扩展 | 常 ✅ |
| `<span id>` | ✅ | ✅ | ✅ |
| 脚注 | ✅ | 看扩展 | 常 ✅ |
| 折叠 details | ✅ | 部分 ✅ | 看版本 |

**稳妥方案：** 标题自动锚点，或 `<span id="短id">`。

## 日报条目推荐模板

可直接复制到 `yz/日报周报/日报.md`：

```markdown
- [7-24](#前端日报2026-7-24郝高尚) — 一句话重点（同步写进目录）

#### 【前端日报】2026-7-24（郝高尚）

> **本日重点：** 一句话
> **主线：** 合同证书 / 解约协议

**今日**
- xxx 【已完成】
- yyy 【进行中】

**风险**（无则整节删除）
- 卡点：… / 等待：…

**明日**
- …
```

或短锚点版：

```markdown
- [7-24](#d-2026-7-24) — 一句话重点

#### <span id="d-2026-7-24">【前端日报】2026-7-24（郝高尚）</span>

> **本日重点：** …
```
