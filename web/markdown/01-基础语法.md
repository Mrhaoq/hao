## 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

渲染：

# 一级标题（示例，文内一般少用）
## 二级标题示例
### 三级标题示例
#### 四级标题示例
##### 五级标题示例
###### 六级标题示例

说明：`#` 数量 = 标题级别；日报条目常用 `####`，但**不是必须**，任意级别都能生成锚点。

## 段落与换行

空一行 = 新段落。

同一段内换行：行尾加两个空格，或直接空一行。

```markdown
第一段。

第二段。

同一段强制换行（行尾两个空格）  
下一行。
```

## 强调

| 写法 | 效果 |
|------|------|
| `*斜体*` 或 `_斜体_` | *斜体* |
| `**加粗**` 或 `__加粗__` | **加粗** |
| `***粗斜体***` | ***粗斜体*** |
| `~~删除线~~` | ~~删除线~~ |

日报里「本日重点」常用引用 + 加粗：

```markdown
> **本日重点：** 解约协议联调与自测
```

> **本日重点：** 解约协议联调与自测

## 列表

无序：

```markdown
- 苹果
- 香蕉
  - 子项（缩进 2 空格）
* 也可用星号
+ 也可用加号
```

- 苹果
- 香蕉
  - 子项（缩进 2 空格）

有序：

```markdown
1. 先做联调
2. 再做自测
3. 最后提测
```

1. 先做联调
2. 再做自测
3. 最后提测

注意：`-#### 标题` 是错误写法（变成列表项，不是标题）。标题必须单独一行，且以 `#` 开头。
