## 和日报的关系

写日报目录时常用：

```markdown
- [7-24](#前端周报2026-7-24郝高尚) — 一句话重点

#### 【前端周报】2026-7-24（郝高尚）
```

详细说明见 [02](./02-标题与锚点.md) 与 [03](./03-链接目录与跳转.md)。
