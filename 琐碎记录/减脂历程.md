## 二、健身历程回顾

### 阶段 1：新手减脂期（前期）

- 采用「高蛋白、极低碳水、极低脂肪」极端饮食
- 平均每周 5–6 次力量 + 5–6 次有氧
- **结果：** 体重下降极慢，严重疲劳、睡眠紊乱、异常饥饿、消化异常
- **教训：** 极端饮食不可持续，身体压力过大反而阻碍减脂

### 阶段 2：调整与恢复（中期）

- 增加碳水和脂肪摄入，降低训练频率
- 体重开始稳定下降（一个月瘦 10 斤）
- 精力、睡眠、恢复明显改善
- **认知升级：** 身体需要「滋养」而非「攻击」

### 阶段 3：腰伤恢复期（近期）

- 搬家导致腰部急性疼痛，暂停下肢大重量训练
- 调整内容：腿举机替代深蹲、臀桥替代硬拉
- 采用「4+2 周」增肌减脂交替策略
- **当前状态：** 腰已痊愈，可正常加入腿训

### 4.4 冷冻蔬菜说明 · 青豆玉米胡萝卜可以吗？

**可以，非常适合备餐。** 市售「三色杂蔬粒」（青豆 + 玉米 + 胡萝卜）出厂前已焯水速冻，无需自己再焯，分装冷冻或直接冷藏取用即可。

| 食材 | 评价 | 注意 |
|------|------|------|
| 青豆 | ✅ 推荐 | 含蛋白和纤维，饱腹感好 |
| 胡萝卜 | ✅ 推荐 | 低热量，β-胡萝卜素丰富 |
| 玉米 | ✅ 可用 | **碳水偏高**，计入主食总量，减脂期控制份量 |
| 三色混合粒 | ✅ 最省事 | 150–200 g/顿直接微波或蒸 |

**搭配建议：**

- 日常：三色粒 150 g + 西兰花 50 g（营养更均衡）
- 增肌期：可多加玉米粒（练前餐多 30–50 g 碳水）
- 减脂期：杂蔬以青豆胡萝卜为主，玉米少放
- 每周 2–3 次补新鲜叶菜（生菜/菠菜快烫），弥补绿叶不足

**与西兰花对比：** 杂蔬粒更方便、便宜；西兰花纤维和饱腹感更好。两者轮换或混用最佳。

### 5.1 核心结论

| 项目 | 标准 |
|------|------|
| 主分化 | **PPL ×3**（腿 / 推 / 拉） |
| 周期 | **4+2**：4 周增肌 → 2 周减脂 |
| 单次力量 | **65–75 min**（含热身） |
| 有氧 | 增肌期 **0**；减脂期 **3×20–30 min** LISS |
| 状态 | 完全恢复；肩主项提前 + 侧束周 2 刺激已并入默认动作表 |

你新手期「每周 5–6 力量 + 5–6 有氧」已验证：**练得多 ≠ 涨得多 / 减得快**。Recomp 靠周期化饮食 + 高质量训练 + 恢复。

| 方案 | 每周健身房时间 | 评价 |
|------|----------------|------|
| 1.5h 力量 + 30min 有氧 × **5 次** | ~10 小时 | ❌ 过量 |
| **65–75min 力量 × 3 次** + 减脂期有氧 ×3 | ~4.5–6 小时 | ✅ **当前最优** |
| 上下肢 ×4（恢复稳定后） | ~5–6 小时 | ⭐⭐ 进阶 |

### 5.2 分化选择

| 分化 | 频率 | 每肌群/周 | 推荐度 |
|------|------|-----------|--------|
| **三分化 PPL**（腿/推/拉） | 3 次/周 | 1 次 | ⭐⭐⭐ **主推** |
| **四分化 上下肢** | 4 次/周 | 2 次 | ⭐⭐ 进阶（跑稳 1–2 个 4+2 后） |
| 五分化 / PPL×2（5–6 天） | 5–6 次/周 | 1–2 次 | ❌ 恢复压力大，非更优 |

**结论：** 先用 PPL×3 把单次练到位；不要靠中午加练升到 5–6 次。

### 5.6 减载与进阶

**减载周（每 2 个 4+2 周期后主动安排 1 周，或提前触发）：**

| 触发 | 做法 |
|------|------|
| 连续 2 周主项掉重量 / 持续乏力 / 关节不适 / 睡眠差 | 组数 **-1**、重量 **-10%**，不冲顶 |
| 每完成 2 轮（约 12 周） | 主动插 1 周减载，再开下一轮 4+2 |

**升级上下肢 ×4（进阶）条件（全部满足再换）：**

- [ ] 连续 4 周主项重量或次数有进步
- [ ] 睡眠稳定 ≥7.5 h
- [ ] 无持续乏力、失眠、肘腕腰肩不适
- [ ] 处于**增肌期**（减脂 2 周仍用 PPL×3）

**上肢 A：** 卧推 4×8-12 → 划船 4×8-12 → 推举 3×10-12 → 下拉 3×10-12 → 侧平举 4×12-15 → 二头 2×12-15

**训练铁律：**

### 7.1 复发处理（关节刺痛）

出现同一位置刺痛（不是普通肌肉酸胀）时：

1. 当天停止触发动作，其余不痛的动作正常练
2. 该动作**降回上一次不痛的重量**，而不是直接归零
3. 2 次训练仍痛 → 该动作暂停 1–2 周，用替代动作（如坐姿推举暂停时用轻夹胸/面拉顶替）
4. 出现夜间痛、明显无力、抬手受限 → **就医评估**，不再自行调整

## 八、核心执行原则

### 训练

- 三分化固定：腿 / 推 / 拉（PPL×3）

- 蛋白保底：训练日 / 休息日均 ≥170 g（减脂期训练日酵母 1.5 勺）

- 蔬菜 ≥500 g/天（杂蔬粒 + 每周补叶菜）
- 水分 3–3.5 L/天
- 咖啡因 **≤15:00**

| 项 | 标准 |
|----|------|

### 刹车（出现即降档）

任一条件 → 组数 -1、重量 -10%、有氧停，或直接进入减载周：

- 连续 3 天睡眠 <7 h
- 主项重量连续 2 周明显下降
- 黏便加重 / 腹痛
- 持续乏力、情绪明显变差

- 冰糖 30 g
- 八角 3 + 桂皮 1 小段 + 香叶 3 + 姜 5 片 + 葱 2 段 + 蒜 5 瓣

3. 加卤料，大火烧开转小火，微沸卤 45–60 分钟
4. 关火浸泡 2 小时以上（过夜更佳）
5. 晾凉去皮，鸡蛋卤 15 分钟后一同浸泡
6. 分装：鸭腿 1 只/袋、卤蛋冷藏、米饭和杂蔬分装冷冻

### 11.8 吃练顺序为什么 D 最优？

| 方案 | 流程 | 开练 | 入睡 | 训练状态 | 恢复 | 推荐 |
|------|------|------|------|----------|------|------|
| A | 18:40 正餐 → 20:10 练 → 回家补粉 | 20:10 | 00:00 | ⭐⭐⭐ | ⭐⭐ | 备选 |
| B | 空腹 → 18:40 练 → 20:30 吃 | 18:40 | 23:30 | ⭐ 没燃料 | ⭐⭐⭐ | ❌ |
| C | 先回家 21:00 练 | 21:00 | 00:30+ | ⭐⭐ | ⭐⭐ | ❌ |
| **D** | **15:30 练前餐 → 18:40 练 → 20:30 正餐** | **18:40** | **23:30** | **⭐⭐⭐** | **⭐⭐⭐** | **✅** |

**D 最优原因：**

1. 练前 2–2.5 h 吃 → 糖原和氨基酸到位
2. 正餐挪到练后 → whole food 恢复窗口更好
3. 比 A 早结束 → 睡眠更稳
4. 不是空腹练 → 腿日不易虚

| 内容 | 普适度 | 说明 |

## 十四、特殊情况处理

### 14.1 生病

| 症状 | 训练 |
|------|------|
| 轻感冒、无发烧 | 减量练，组数 -2，不冲重量 |
| 发烧、流感 | **完全休息**，恢复后再练 |
| 肠胃炎 | 休息，蛋白改粉剂易消化 |
| 恢复后第一次 | 重量 -10%，不冲 |

**铁律：生病不练大重量，恢复优先于进度。**

### 14.2 出差/旅行

- 优先：找酒店健身房，至少做 1 次腿/推/拉精简版
- 无健身房：弹力带划船+俯卧撑+深蹲+平板，15 min 也行
- 饮食：便利店茶叶蛋+饭团+牛奶凑蛋白，凑够 120 g 即可
- 不必强求 170 g，短期 120 g 不会掉肌肉

### 14.3 应酬/聚餐

- 训练日安排在聚餐前练，练后正餐就是聚餐
- 聚餐多吃蛋白（肉、鱼、豆腐），少喝酒
- 酒精：影响恢复，当天不练；偶尔 1–2 杯可接受
- 第二天正常练，不用「惩罚性加练」

### 14.4 连续加班周（3 天以上没练）

- 不要一次补 3 练，按正常节奏重启
- 优先重启：腿 → 拉 → 推
- 饮食蛋白维持，不因没练就降蛋白
- 当周可算减载周，组数 -1

### 14.5 消化异常 · 黏便（2026-07-20 起追踪）

> 与新手期「消化异常」同类信号；问 AI 原文见 [§15](#十五健康咨询记录问-ai)。  
> **当前执行以 [§五](#五训练方案) + [§十八](#十八时间轴与追踪2026-08-10-起) 为准**；黏便加重时先停乳清、蔬菜减量，必要时插减载。

| 症状 | 可能关联 | 先试调整 |
|------|----------|----------|
| 大便很黏 | 乳清/酵母 + 纤维偏高 + 冷冻备餐 | 乳清停 3–5 天；蔬菜 100–150 g/顿；粉随餐 |
| 伴腹痛/血便/发热 | 非单纯饮食 | 休息；必要时就医 |

### 2026-07-20（一）· 黏便 + 睡眠仍差

**自述：** 最近拉屎很黏；睡眠依旧不好。

**对照文档结论：**

- 已踩「松一档 / 减载」触发线（见 13.3、5.9；[噩梦记录](./噩梦记录.md) 中期清单）。

1. 乳清减半或停；缺口用食物蛋白/酵母顶，避免粉剂叠满。

5. 红线：腹痛、血便、发热 → 休息/就医，勿硬练。

- 减脂松一档或提前回维持（少抠 200–300 kcal）。
- 有氧先停；力量组数 -1、重量 -10%（等同减载周）。
- 乏力、失眠 → 休息 1 天，不是加练。

### 2026-07-20（一）· 如何增加睡眠时长与质量

**目标：** 08:10 起 → 训练日 **23:30 前躺床**（≥7.5 h）；休息日尽量 **23:00**。

**时长（硬指标）：**

| 做法 | 说明 |
|------|------|
| >21:30 不开练 | 方案 D 铁律 |
| 睡眠差时砍晚间有氧 | 更早结束 → 更早正餐 → 更早躺床 |
| 减脂松一档 | 赤字抬皮质醇，直接伤睡眠质量 |

**质量：**

- 咖啡因 **≤15:00**（茶、功能饮料也算）。
- 练后正餐 **20:30–21:00** 吃完；睡前 1–1.5 h 不再大吃。
- 通风、别太热、被子别捂太紧；睡前 30–40 min 降光 + 呼吸 5–10 轮（鼻吸 4s → 停 1–2s → 嘴呼 6–8s）。
- 午睡 **≤20 min**，**14:00 前**，设闹钟。
- 睡眠差周：力量减量，有氧先停。

**本周最小清单：**

- [ ] 咖啡因 ≤15:00
- [ ] 训练日 23:30 / 休息日 23:00 躺床
- [ ] 减脂松一档 + 砍晚间有氧
- [ ] 睡前呼吸连续 ≥5 晚
- [ ] 复盘/情绪话题限时 15–20 min/天

**就医：** 喘、心慌、胸闷反复 → 呼吸/心内科；连续多周难入睡、白天功能明显下降 → 睡眠/心理科。

### 2026-07-20（一）· 上午打瞌睡但精神尚可

**自述：** 晚上睡眠不好 → 上午打瞌睡；精神还好，不算特别昏沉。

**解读：**

- 典型「睡眠债未还清 + 代偿尚可」——深睡/连续睡眠仍不足，但咖啡因/工作刺激/意志仍撑住。
- **不是绿灯：** 容易误判为「还能撑」，继续晚训硬减脂；缓冲耗尽后才暴雷（噩梦、乏力、主项掉重量）。

**应对：**

| 时段 | 做法 |
|------|------|
| 上午 | 10–20 min 午睡/趴桌（14:00 前）；走动、见光；咖啡尽量午前 |
| 晚上 | 仍执行 23:30 躺床 + 降训练/减脂负荷 |
| 观察 | 若仅上午困、下午正常、夜里逐步拉回 7.5 h → 1–2 周常可缓解 |

**升级：** 全天靠撑、注意力明显差、连续浅睡/噩梦、再叠加喘/心慌 → 按就医红线处理。

### 2026-07-20（一）· 非分手因素对睡眠的影响（摘要）

### 17.1 为什么肩显弱：当前训练里的结构性原因

对照 §5 原推日/拉日动作表：

| 部位 | 原频率 | 问题 |
|------|--------|------|
| 前束 | 卧推 + 上斜卧推 + 坐姿推举，约 **2–3 次/周**（间接+直接） | 不缺 |
| **侧束（宽度担当）** | 仅推日侧平举 **1 次/周** | **偏低**——宽度肩最吃侧束频率，1 次/周偏少 |
| 后束 | 推日俯身飞鸟 + 拉日面拉，约 **2 次/周** | 尚可，但组数偏少（2–3 组） |

**结论：** 「肩弱小」大概率不是练得不对，而是**侧束刺激频率不够**（一周就练 1 组超组），后束容量也偏薄。加强方向：把侧束拉到 **2 次/周**，后束组数提上去，前束维持不用额外加量。
