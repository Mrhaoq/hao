# Wooting 60HE v2 · 磁轴选型与对比

> 整理日期：2026-07-17  
> 目标键盘：**Wooting 60HE v2**（热插拔霍尔 PCB，官方标配 Lekker Tikken Medium）  
> 说明：磁轴 = Hall Effect / 磁力感应轴，需磁铁朝向与 PCB 传感器匹配；不可装进普通机械轴键盘。  
> 价格、库存以官方/零售页为准，本文侧重手感、行程、稳定性与社区共识。

---

## 一、先说结论（怎么选）

| 你的需求 | 更推荐 | 理由（一句话） |
| -------- | ------ | -------------- |
| 开箱即用、少折腾 | **原装 Lekker Tikken Medium** | v2 就是为它调的；声、稳、程都明显好于旧 Lekker |
| 更稳、更「干爽/干净」的触底，偏竞技短行程 | **Geon RAW HE（尤其 50gf）** | Wooting 店有售；晃动极小；3.4 mm 行程偏快手感 |
| 更深、偏打字「麻将/marbly」声，社区口碑极高 | **Gateron Magnetic Jade Pro** | 稳、回弹好；比原装 Jade 更控、更顺 |
| 想轻、便宜试水第三方 | **Gateron Magnetic Jade（标准版）** | 约 30gf 起步，顺滑；略轻、公差不如 Pro |
| 已有旧板、只想复刻「以前的 Lekker」 | **Lekker L60 v2** | 仍兼容；但同价不如直接上 Tikken |
| 要静音向 | **Glorious Lynx Silent / Gamakay Phoenix Silent** 等 | 可选，但手感与 RT 手感因人而异；先确认磁极方向 |

**一句话：**  
- 新买 **60HE v2** → 先用 **Tikken** 一两周再决定要不要换。  
- 旧 **60HE / 60HE+** 嫌晃、嫌脆响 → **Tikken** 或 **Jade Pro / Geon RAW** 都是主流升级。

## 二、兼容性速览（60HE v2）

- PCB 为霍尔感应，热插拔；换轴一般 **不用改固件**，插上后在 Wootility 里重新校准/微调触发即可。  
- 磁铁需 **朝向 PCB（north-facing / 磁极朝下）**；买错朝向会没信号或行程异常。  
- Wooting 官方店目前主推/有售的相关轴大致包括：  
  - **Lekker Tikken**（v2 标配）  
  - **Lekker L60 / L45 v2**  
  - **Geon RAW HE**  
  - **Gateron Jade** 系列  
- 社区常测可用（以实测为准）：Gateron KS-20 / KS-20T（Jade）、Jade Pro、TTC Magneto、Kailh Source、部分 Everglide / WS Dash 等。  
- **注意：** Gateron 部分型号（如部分 KS-37 / Keychron Nebula 系）磁通量/磁极设计不同，**不一定**兼容 Wooting；买前确认「Wooting / KS-20 系」兼容说明。

## 四、详细对比（按维度）

### 1. 手感与克数曲线

| 轴 | 按下感受 | 适合谁 |
| -- | -- | | ---- |
| **Tikken** | 起压略沉（~42），触底不特别重（~54）；长簧让前段更「有控制感」，误触更少 | 不想太轻、又要一天打字+游戏的人 |
| **L60 v2** | 起压接近 Tikken，但短簧 + 触底更重（~60）；整段更「硬触底」 | 习惯旧 Wooting 手感者 |
| **Jade** | 明显更轻（~30 起），顺滑；长时间打字轻松，误触靠软件触发点补 | 喜欢轻轴、指力小 |
| **Jade Pro** | 比 Jade 略沉（~36），**20 mm 簧回弹更快**；控场感更好 | 多数第三方升级首选 |
| **Geon RAW** | L50：36→50，线性干净；几乎无多余摩擦；行程短，触底更快到来 | 竞技、要「每次按都一样」 |

### 2. 行程与 Rapid Trigger（RT）

- **4.0 mm（Tikken / L60）**：行程更深，触底反馈更「完整」；浅触发时仍有大量余程可做 RT。  
- **3.5 mm（Jade / Jade Pro）**：更接近很多国产 HE 手感；RT 仍强，但触底更早。  
- **3.4 mm（Geon RAW）**：最短一档之一；偏「快、脆、早触底」；FPS 里 WASD 微调手感更紧凑。  

> RT / 模拟输入质量主要靠 **Wootility + PCB**，轴体差异更多在 **稳定性、声、力曲线、触底质感**，而不是「能不能开 RT」。

### 3. 稳定性（轴晃）

从社区与评测的大致排序（主观）：

**Geon RAW ≈ Jade Pro ≥ Tikken ≫ L60 v2 / 早期 Lekker**

- 旧 Lekker 的「晃」是 60HE 一代最常被喷的点。  
- Tikken 用更紧公差显著改善横向晃动；纵向仍非绝对第一。  
- Geon RAW、Jade Pro 常被形容「几乎无晃 / 很稳」。

### 4. 声音

| 轴 | 声线简述 |
| -- | -------- |
| **Tikken** | 最大升级点之一：顶出 clack 几乎被压掉，触底更深更静，整体偏 **thock / muted**；在铝壳 v2 上评价很高 |
| **L60 v2** | 更空、更脆，典型旧 HE「塑料顶出」 |
| **Jade** | 偏亮、麻将/clack 感 |
| **Jade Pro** | 比 Jade 更干净、略深；对比 Tikken 仍可能更「脆」一点（评测常说 Tikken 更深更静） |
| **Geon RAW** | 半封闭底：触底时小孔被堵住，声线独特；整体干净 |

### 5. 结构与改装友好度

| 轴 | 结构要点 | 改装注意 |
| -- | -------- | -------- |
| **Tikken** | 封闭底 + 软 PC 混料上盖 | 声学好；**拆轴扣位偏软**，整批拆润滑要小心掰扣 |
| **L60 v2** | 透明上盖、短簧 | 易拆；声学一般 |
| **Jade / Pro** | 标准 KS-20 系结构；Pro 拔插力与导光有加强 | 出厂润滑通常够用；Pro 更推荐直接用 |
| **Geon RAW** | 半封闭底；兼容 Wooting 弹簧包 | 可换官方弹簧微调克数 |

### 6. 与 60HE v2 整机的搭配

v2 本身已带：**FR4 定位板、摩擦安装、Poron/硅胶夹层、PET + tape、可选铝壳/EPDM**。  
→ 原厂声学已经偏深、偏整齐。  

- 继续用 **Tikken**：整机设计意图，最省事。  
- 换 **Geon RAW**：手感更「稳、短、干净」，声线会变，不一定更深。  
- 换 **Jade Pro**：偏社区经典「升级包」；在 v2 上属于口味选择，不一定「全面碾压」Tikken（不少新评测认为 Tikken 声学已超过 Jade Pro）。

## 六、换轴实操（60HE v2）

1. 断电 / 拔线；用拔轴器垂直拔出（注意 Tikken 上盖较软，别硬掰壳体）。  
2. 确认新轴 **磁铁朝向正确**（朝 PCB）。  
3. 插满后打开 **Wootility** → 校准 / 检查各键模拟行程是否一致。  
4. 重新设：触发点、RT、死区；不同行程的轴（4.0 vs 3.4/3.5）建议重调一遍手感。  
5. 若个别键漂移：先重新校准，再检查轴是否插到底、磁铁是否偏移。

## 七、不建议 / 易踩坑

- 买 **非 HE / 无磁铁** 的普通机械轴 → 完全不能用。  
- 买 **磁极朝向错误** 或 **磁通量不匹配**（部分 KS-37 / 特定品牌专用轴）→ 无响应或不准。  
- 以为换轴能「大幅降低延迟」→ 延迟主要看轮询与固件；v2 已是 8 kHz，换轴收益在手感与声。  
- 未校准就开极浅 RT → 容易误触，尤其轻轴（Jade）。
