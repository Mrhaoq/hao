# Wooting 60HE v2 · 磁轴选型与对比（市面常见轴）

> 整理日期：2026-07-17（更新：扩充市面常见轴 + 中文名）  
> 目标键盘：**Wooting 60HE v2**（热插拔霍尔 PCB，官方标配 **乐客·蒂肯轴**）  
> 说明：磁轴 = Hall Effect / 霍尔磁轴；需 **N 极朝下** 且磁通量匹配 Wooting PCB。普通机械轴不能用。  
> 价格、库存以官方/零售页为准；兼容以 **实测 + 磁极** 为准，买前再核对。

## 一、先说结论（怎么选）

| 你的需求 | 中文名（英文名） | 理由（一句话） |
| -------- | ---------------- | -------------- |
| 开箱即用、少折腾 | **乐客·蒂肯轴**（Lekker Tikken Medium） | v2 原配；声、稳、程综合最好 |
| 更稳、短行程、偏竞技 | **Geon RAW 磁轴**（Geon RAW HE，50gf 档） | 几乎无晃；3.4 mm 触底快 |
| 第三方升级经典 | **佳达隆磁玉 Pro 轴**（Gateron Magnetic Jade Pro） | 稳、回弹好；社区口碑高 |
| 想轻、顺滑 | **佳达隆磁玉轴**（Gateron Magnetic Jade） | ~30 gf 起；便宜试水 |
| 要物理抗晃、长簧跟手 | **TTC 万磁王轴**（TTC King of Magnetic / KOM） | 榫卯+防尘墙；21 mm 簧 |
| 预算友好、声线偏机械 | **阿珂星链磁轴**（Akko Astrolink） | N 极兼容 Wooting；性价比高 |
| 比星链更闷、更深声 | **阿珂星瞄磁轴**（Akko AstroAim） | 同系升级；触底更重 |
| 旧 Wooting 复刻手感 | **乐客 L60 v2 磁轴**（Lekker L60 v2） | 仍兼容；同价不如蒂肯 |
| 要静音向 | **荣耀 Lynx 静音磁轴** / **咖曼凤凰静音磁轴** 等 | 真静音 HE 选择少；先确认 N 极 |
| 重手、长行程 | **GUGU 黑骑士磁轴**（GUGU Black Knight） | ~4.1 mm + 55 gf；偏沉 |

**一句话：**  
- 新买 **60HE v2** → 先用 **蒂肯** 一两周。  
- 想换第三方 → **磁玉 Pro / Geon RAW / 万磁王** 三选一按口味；预算紧看 **星链/星瞄**。  
- **别买 KS-37、阿珂旧 S 极 HE 黄轴** 等不兼容型号。

### 2. 行程与 Rapid Trigger（RT）

| 行程档 | 代表轴 | 特点 |
| ------ | ------ | ---- |
| **4.0 mm+** | 蒂肯、L60、黑骑士、乾轴 | 深触底、RT 余量大；偏打字完整感 |
| **3.5 mm** | 磁玉全系、Dash、粘米 | 国产 HE 主流档 |
| **3.4 mm** | Geon RAW/猛禽、万磁王、星链 | 偏短、偏竞技 |
| **3.3 mm 及以下** | HMX 水晶、DUHUK 赫兹 等 | 极短；需软件细调防误触 |

> RT 能力看 **Wootility + PCB**；换轴主要改 **稳、声、力曲线**。

### 3. 稳定性（轴晃）大致排序

**Geon RAW ≈ 磁玉 Pro ≈ 万磁王 ≈ 磁玉 Gaming ≥ 蒂肯 ≫ L60 v2 ≈ 早期 Lekker**

- 蒂肯：横向大幅改善；纵向仍非绝对第一。  
- 万磁王：榫卯 + 防尘墙，国产抗晃标杆之一。  
- 磁玉 Pro / Gaming：Pro 稳；Gaming 盒形轴心更抗晃。  
- 阿珂星链/星瞄：够用，极端浅 RT 不如第一梯队稳。

## 八、换轴实操（60HE v2）

1. 断电拔线；垂直拔轴（蒂肯上盖软，勿硬掰）。  
2. 确认 **N 极朝下** 插入。  
3. Wootility **全键校准**。  
4. 重设触发点、RT、死区（3.4 / 3.5 / 4.0 mm 轴混用建议统一方案）。  
5. 单键异常：重插 → 校准 → 换颗试。
