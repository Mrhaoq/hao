## 解梦核心

> **"我身边的人，是会突然变成我认不出、会伤害我的样子的，而我还得负责去应对。"**

### 三层对应

| 梦境               | 新工作（1 个月）             | 分手（1 个月）     | 童年模式                     |
| ------------------ | ---------------------------- | ------------------ | ---------------------------- |
| 不认识的同事能变形 | 新同事还不了解，不知谁会翻脸 | 前任"变了一个人"   | —                            |
| 心情不好就变       | 职场观察"谁情绪不稳"         | 对前任情绪化的记忆 | 家里可能有"心情不好就变"的人 |
| 会吃人             | 怕被背锅/针对/淘汰           | 怕被余波吞噬       | —                            |
| 搏斗 + 哄          | 新职场情绪劳动               | 曾长期安抚对方情绪 | 早就学会"哄别人"             |
| 老家               | —                            | 退回最根本安全基地 | 触及原生家庭层面             |

### 棕熊的画像

平时温和笨重 → 被激怒就致命。= 心里对"情绪化的人"的浓缩印象：平时没事，一旦心情不好就变成认不出、会伤害你的样子。

## 行动清单

### 今晚最小行动

- [ ] 训练减量或改轻松活动（不减脂也先降一档）
- [ ] 晚餐别太晚，咖啡因截止到下午
- [ ] 房间通风、别太热；被子别捂太紧
- [ ] 睡前慢呼吸：鼻吸 4s → 停 1-2s → 嘴呼 6-8s
- [ ] 噩梦醒了先开灯坐稳，喝口水，确认"我在现实里"

### 中期调整

- [ ] 减脂节奏松一档（身体已在报警）
- [ ] 前任若有纠缠/未了事项 → 设边界
- [ ] 新工作先观察别急着讨好
- [ ] 白天承认："我是不是在管理别人的情绪？"

### 就医红线

- 喘憋反复或休息后仍明显
- 噩梦连续多天、白天困倦/注意力差
- 伴心慌、胸闷、血压异常
- → 先看**呼吸/心内科**排除器质问题；睡眠持续差再考虑睡眠/心理科
