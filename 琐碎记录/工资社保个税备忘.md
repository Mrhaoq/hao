## 六、个税档位与临界点

### 月薪：不存在「到手变少」的临界点

累进税率 + 速算扣除数在档位衔接处是连续的，**税前越高，到手一定越高**。跨档只是每多赚 100 元能留到手的比例下降，不是总到手变少。

应纳税所得额 = 税前 × 82.5% − 5000 − 专项附加扣除

### 月薪档位对应税前（专项附加扣除按 2000）

| 个税档位 | 应纳税所得额 | 对应税前约 | 每涨 100 税前，到手约 |
| -------- | ------------ | ---------- | --------------------- |
| 免税 | ≤ 0 | ≤ 8485 | +82.5 元 |
| 3% | 0 ~ 3000 | 8485 ~ 12121 | +80 元 |
| **10%** | 3000 ~ 12000 | **12121 ~ 23030** | **+74 元** |
| 20% | 12000 ~ 25000 | 23030 ~ 38788 | +66 元 |
| 25% | 25000 ~ 35000 | 38788 ~ 50909 | +62 元 |
| 30% | 35000 ~ 55000 | 50909 ~ 75152 | +58 元 |

### 税前 14000 在哪个档？

专项附加扣除 2000 时：

- 应纳税所得额 = 14000 × 82.5% − 5000 − 2000 = **4550**
- 落在 **10% 档**（3000 ~ 12000），**不是 20% 档**
- 进 20% 档需税前 **> 23030**（专项扣除 2000 时）

### 年终奖单独计税：存在「坑区」

| 年终奖 | 税后到手 | 说明 |
| ------ | -------- | ---- |
| 36000 | 34920 | 3% 档上限 |
| **36001** | **32610.9** | 多 1 元，少拿约 2309 |
| 38567 | 34920.3 | 才回到 36000 的水平 |
| 144000 | 129810 | 10% 档上限 |
| **144001** | **116610.8** | 多 1 元，少拿约 13199 |

> 年终奖单独计税政策延续至 2027 年底。若公司发年终奖且单独计税，避开 36001、144001、300001 等区间。

## 七、上海缴社保、杭州办公：能不能用？

### 总原则

- 社保公积金缴在上海，**不等于作废**，但杭州使用大多需要**提前备案或转移**
- 长期在杭州办公，最干净的做法是要求公司在**杭州本地缴纳**

### 各险种

| 险种 | 杭州能否用 | 说明 |
| ---- | ---------- | ---- |
| 医保 | 能，需备案 | 住院、门诊、部分药店都可直接结算 |
| 养老 | 不涉及「使用」 | 年限可转移接续，退休时归集 |
| 失业 | 一般在上海申领 | 跨省可转移 |
| 工伤 | 杭州出工伤，上海认定支付 | 保留外派/办公证明 |
| 生育 | 异地生育建议提前备案 | 否则先自费再回上海报销 |
| 公积金 | 能，分场景 | 租房提取、长三角异地公积金贷款还贷提取、或转移接续到杭州 |

### 公积金在杭州的使用方式

1. **租房提取**：在杭州无房且租房，可提上海公积金付房租
2. **长三角异地公积金贷款还贷提取**（2024-06-01 起）：在浙江用公积金贷款买房后，可提取上海公积金还贷；**不含商业贷款**；先还后提
3. **转移接续**：长期在杭州发展，可通过「全国住房公积金」小程序把上海公积金转到杭州

## 八、异地就医备案（重点）

### 不备案会怎样？

| 场景 | 不备案 |
| ---- | ------ |
| 住院 | 不能直接结算，需先全额自费 |
| 普通门诊 | 不能直接结算 |
| 急诊 | 视同自动备案 |
| 药店买普通药 | 基本刷不了医保，只能现金 |
| 药店买双通道药 | 未备案需自付 20% 后结算 |

> 不备案 ≠ 医保作废。钱还在上海账户里，回上海照常能用；只是在杭州用不了。

### 三种支付方式（别搞混）

| 方式 | 钱从哪出 | 算不算报销 |
| ---- | -------- | ---------- |
| 统筹报销（按比例） | 医保基金 | 是，如报 70% 自付 30% |
| 个人账户支付 | 医保卡里自己的钱 | 否，花的是账户余额 |
| 现金自费 | 口袋现金 | 否 |

**普通药店买普通药，从来不是「按比例报销」：**

- 已备案 + 联网药店 → 用**个人账户余额全额付**（余额不够再现金补）
- 未备案 → **全额现金**
- 想按比例报销买药 → 去**社区卫生服务中心门诊**开药，不走药店

### 备案类型怎么选

| 备案类型 | 材料 | 有效期 | 适合我吗 |
| -------- | ---- | ------ | -------- |
| 常驻异地工作人员 | 外派证明 / 异地劳动合同 / 个人承诺书 | 1 年 | 公司出证明时可用 |
| **异地长期居住人员** | **居住证 / 户口簿** | **2 年** | **有杭州居住证首选，不需公司配合** |
| 其他临时外出就医 | 免证明 | 6 个月 | 救急，有效期短 |

### 个人承诺制的坑

- 公司不出外派证明时，可签《个人承诺书》先办备案
- 但承诺制有效期仅 **30 日**，30 日内必须补齐工作证明或异地劳动合同
- 逾期备案失效，且**以后不能再走承诺制**；已结算的可能纳入医保信用评价

### 事后补办

| 时机 | 结果 |
| ---- | ---- |
| **出院结算前**补办 | 备案日期回溯到入院前，**可直接联网结算**，不用垫全款 |
| 出院后补办 | 先自费，再回上海手工报销（麻烦） |
| 门诊当场缴费前补办 | 可直接刷医保 |
| 门诊已自费 | 补办后手工报销 |
| 补办时间限制 | 备案开始日期距申请日不超过 **60 日** |

> 住院不是「先付全款再治病」：入院交的是押金，真正结算是**出院当天**。出院前补办备案完全来得及。

### 办理渠道

- 国家医保服务平台 APP
- 国家异地就医备案小程序
- 上海「随申办」APP
- 备案后可在 APP 查杭州支持异地联网结算的医院/药店名单

## 九、备案实操建议（按优先级）

1. **首选**：在杭州办居住证 → 以「异地长期居住人员」备案（2 年，不依赖公司）
2. **次选**：和公司沟通出具外派证明 → 以「常驻异地工作人员」备案（1 年）
3. **救急**：先签个人承诺书（30 天），期间补材料或转办居住证备案
4. **根本解法**：要求公司在杭州直接缴社保公积金

## 十一、相关公式

```
个人五险一金 = 税前 × 17.5%
应纳税所得额 = 税前 × 82.5% − 5000 − 专项附加扣除
实际到手 = 税前 − 个人五险一金 − 个税

反推税前（近似）：
所需税前 ≈ (目标到手 + 速算扣除相关项) / (1 − 0.175 − 适用税率×0.825)
```
