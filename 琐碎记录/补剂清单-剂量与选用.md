# 个人补剂清单 · 剂量与选用说明

> 整理日期：2026-07-30  
> 适用：82 kg · 方案 D · 约会减脂冲刺期（饮食/训练以 [减脂历程.md](./减脂历程.md) §十六为准）  
> **性质：** 个人备忘 + 一般性营养建议，**非医学诊断/处方**。肝病、用药、手术、出血倾向等请先问医生。

相关：[减脂历程 §六](./减脂历程.md#六补剂使用) · [方案D一页纸总览](./方案D一页纸总览.md) · [周末备餐](./周末备餐操作清单.md)

---

## 一、一页结论（先看这个）

| 层级 | 补剂 | 要不要 |
|------|------|--------|
| **核心（建议常备）** | 酵母蛋白、乳清（训练日）、肌酸、鱼油 | ✅ |
| **可选（按需）** | 牡蛎片（锌）、维生素 D、褪黑素、镁 | 看症状/季节 |
| **一般不需要** | 护肝片、堆叠一堆「增肌黑科技」 | ❌ 无指征别吃 |

**蛋白总目标：** 全天食物 + 粉剂 ≥ **170 g**（减脂冲刺同）。  
**鱼油按有效成分算：** 每天 EPA+DHA 合计约 **700–1000 mg**（不是纯度 %，也不是「几粒鱼油」瞎数）。

## 二、核心补剂（建议执行）

### 2.1 酵母蛋白粉（约 75% 蛋白）

| 项 | 标准 |
|----|------|
| **用途** | 凑蛋白；训练日练前餐；休息日顶替乳清缺口 |
| **训练日** | 维持/增肌：**1 勺**（15:30）；**减脂冲刺：1.5 勺**（15:30） |
| **休息日** | **下午 1.5–2 勺（优先 2 勺）**，否则全天蛋白只剩 ~115 g |
| **怎么喝** | 随餐或少量碳水一起；少空腹冰水猛灌 |
| **注意** | 黏便排查对象之一；不适可略减，缺口用食物蛋白补 |

### 2.2 乳清蛋白粉（约 75% 蛋白 · 约 20–22 g/勺）

| 项 | 标准 |
|----|------|
| **用途** | 训练日练后补蛋白 |
| **剂量** | **训练日 1 勺**；休息日 **0** |
| **时机** | 约 **21:00**（练后正餐后）+ 肌酸 |
| **冲刺例外** | **黏便期 / W1 软启动：停乳清**；蛋白用食物或酵母补 |
| **注意** | 乳糖不耐或黏便时优先停这个，不是停肌酸 |

### 2.3 肌酸一水合物

| 项 | 标准 |
|----|------|
| **剂量** | **5 g/天，每天都吃**（训练日、休息日一样） |
| **时机** | 训练日随乳清；停乳清或休息日 → 随酵母/随餐即可 |
| **加载** | 不需要；直接每天 5 g |
| **注意** | 多喝水；少数人夜尿/轻微水肿属常见反应 |

### 2.4 鱼油（Omega-3）

| 项 | 标准 |
|----|------|
| **目标** | 每天 **EPA + DHA 合计约 700–1000 mg** |
| **起步** | 先按标签算到约 **700 mg**（赛霸若标称 EPA 375 + DHA 300 ≈ 675 mg → **约 1 粒/天**） |
| **可加到** | 胃稳、无反酸腥气 → 可到合计约 **1000–1350 mg**（赛霸约 **1–2 粒**） |
| **时机** | **随含脂肪的正餐**（午餐或练后正餐）；勿空腹 |
| **怎么选** | 看瓶身每粒 **EPA ___ mg、DHA ___ mg**；纯度 75% 实标可用且常更划算；95% 宣传要防虚标 |
| **问商家话术** | 见下方 [第六节](#六问商家鱼油标准可复制) |
| **一般不需要** | 为「更纯」盲目加到治疗级 2–4 g/天（那是医嘱档） |

**换算口诀：**  
`每天需要的粒数 ≈ 目标 EPA+DHA(mg) ÷ 每粒 EPA+DHA(mg)`

## 三、可选补剂（按需）

### 3.1 牡蛎片（补锌）

| 项 | 标准 |
|----|------|
| **当前** | 文档写「每日随餐，可继续」 |
| **建议** | 看清标签**元素锌 mg/天**；成年男一般膳食 + 补剂合计不宜长期远超常见上限（约 40 mg/天 量级，以标签与医嘱为准） |
| **时机** | 随餐 |
| **注意** | 已吃复合维生素含锌时，避免叠太多 |

### 3.2 维生素 D

| 项 | 标准 |
|----|------|
| **参考剂量** | **800 IU/天**（约 20 μg）随餐 |
| **更适合** | 秋冬、长期室内、日晒少 |
| **说明** | §6.1 有写；§6.2 实际执行表曾未列入 → **可选补上** |
| **加量** | 若体检 25(OH)D 偏低，按医生建议，勿自行猛加 |

### 3.3 褪黑素（助眠 · 短期）

| 项 | 标准 |
|----|------|
| **剂量** | 先试 **0.3–1 mg**；多数 **1–3 mg** 足够；避免一上来 5–10 mg |
| **时机** | 计划上床前 **30–60 min**（23:30 躺床 → 约 22:30–23:00） |
| **周期** | 先用 **1–2 周**观察；节奏稳住后逐步停 |
| **优先级** | 行为（23:30 躺床、咖啡因 ≤15:00、降训练负荷）> 褪黑素 |
| **注意** | 可能次日犯困、梦更生动；勿与酒精/镇静药自行叠加 |

### 3.4 镁（助放松 · 可选）

| 项 | 标准 |
|----|------|
| **形式** | 甘氨酸镁 / 柠檬酸镁较常用 |
| **剂量** | 约 **200–300 mg 元素镁**/晚（看标签「镁」不是化合物总重） |
| **注意** | 腹泻则减量；与部分药物可能相互影响，长期用药先问药师 |

## 四、一般不建议（无指征）

| 补剂 | 结论 |
|------|------|
| **护肝片** | 无肝病、不酗酒、肝功能正常 → **不必为健身特意吃**；异常先体检/就医 |
| 睾酮助剂、各种「增肌神药」 | 不在本方案内 |
| 同时新开一堆补剂 | 出问题无法排查；**一次只改一个变量** |

## 五、按日类型速查

### 训练日（减脂冲刺）

| 时间 | 补剂 |
|------|------|
| 午餐随餐 | 鱼油（按 EPA+DHA 算粒数）· 牡蛎片 ·（可选维生素 D） |
| 15:30 | 酵母 **1.5 勺** + 香蕉 + 面包 |
| 21:00 | 乳清 **1 勺**（黏便则停）+ **肌酸 5 g** |
| 睡前（仅失眠周） | 可选褪黑素 0.3–1 mg；可选镁 200–300 mg |

### 休息日

| 时间 | 补剂 |
|------|------|
| 下午 | 酵母 **2 勺** |
| 随餐 | 鱼油 · 牡蛎片 ·（可选维生素 D） |
| 任意一餐 | **肌酸 5 g**（不依赖乳清） |
| — | **不加乳清** |

## 六、问商家鱼油标准（可复制）

```
你好，想确认鱼油有效成分，请按瓶身/标签回答：
1）每粒 EPA 多少 mg？DHA 多少 mg？
2）每粒鱼油总量多少 mg？
3）形态是 rTG / TG / EE 哪一种？
4）有没有本批次第三方检测报告（如 IFOS）？请发链接或批号。
谢谢。
```

**合格回答：** 说得出每粒 EPA/DHA 毫克数。  
**不合格：** 只喊「95% 纯度」「每粒 1000mg 鱼油」。

## 七、异常时怎么停（简表）

| 情况 | 处理 |
|------|------|
| 黏便 | **先停乳清** 3–5 天；酵母可略减；粉随餐 |
| 睡眠差 | 优先作息；褪黑素仅短期辅助 |
| 鱼油反酸/腹泻 | 减粒数或换随大餐；仍不适则暂停 |
| 右上腹痛、黄疸、尿深黄 | **就医**，别自行加护肝片硬顶 |
| 手术前 / 抗凝药 | 鱼油等先问医生 |
